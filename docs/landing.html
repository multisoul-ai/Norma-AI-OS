Product idea

不是工具集合，是一起做事的伙伴。

Norma OS 把终端、文件、界面、图表、分析和 Agent 对话放进同一个空间里。你看到的不只是回答，而是工作正在发生。

01

Live Agents

Planner、Builder、Reviewer、Researcher 可以并行工作，每个 Agent 都有自己的任务节奏和状态信号。

02

Terminal Contexts

Terminal 是第一个 Live Node。命令、日志、测试、diff 和输出结果留在原位，随时可继续。

03

Infinite Canvas

工作不是一条聊天记录，而是一张能承载节点、产物、过程与决策的无限画布。

Product obsession

把过程和结果都摆到你面前。

高密度但不吵闹。深色玻璃承载内容，高饱和色只作为状态、角色和协作节奏的信号。

同一空间

Agent 产出的代码、文档、图表和 UI 不是隐藏在消息里，而是成为画布上的可见节点。

实时对话

你可以用自然语言分配任务，也能回到终端、文件和节点中继续精确操作。

可交付成果

从探索到验证再到交付，Norma OS 让每个 Agent 的工作痕迹和结果保持可追踪。

Workflow

一次对话，多条任务线。

面向开发工作的协作模型：你保留判断和方向，Agent 在不同终端上下文里推进具体任务。

1

描述目标

告诉 Norma OS 要构建、修复、分析或整理什么，系统把目标拆成可协作的 Agent 任务。

2

Agent 并行执行

每个 Agent 进入自己的终端和上下文，生成文件、运行命令、检查结果并同步状态。

3

在画布里收敛

代码、界面、图表、报告与决策节点留在画布上，形成可回看、可继续的工作空间。
