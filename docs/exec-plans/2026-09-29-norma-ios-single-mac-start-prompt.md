页面必须按 `docs/product-specs/norma-ios-ideas-workspaces-2026-09-28` 和 `docs/product-specs/norma-ios-prototypes-2026-09-26` 的适用原型一比一还原，以现行 iOS 样式规范明确的来源优先级处理冲突。保持浅色 iOS 设计、原生导航和手势，导航、Sheet 与浮动功能层使用系统 Liquid Glass 并提供旧系统回退；还原动效、键盘、返回、草稿保留及状态反馈，缺少必要素材可生成。每完成页面运行相关自动化测试，用 Computer Use 操作模拟器中的真实原生 App，保存同尺寸截图；启动独立、只读的 UI／交互验收子 Agent，发现偏差必须修复并重新验收，直到对应项目复核 PASS。
