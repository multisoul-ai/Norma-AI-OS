## 本轮修正

1. 慢请求读正文时会让出执行权；正文到齐后重新读取设备状态，保证这期间发生的撤销、额度扣除、回合去重生效。真实本地 HTTP 测试先复现重复回合错误返回 200，再修到 409；同组覆盖额度 429、撤销 403。
2. 启动时检查设备状态的内部字段。合法 JSON 中损坏的 `turn_ids` 原先继续按撤销记录处理，现在统一返回 503 并保留原文件；非法 JSON 同样拒绝。
3. Nginx 去除重复缓冲指令，把请求体上限从 4 KiB 调为 32 KiB，与文字协议一致；语音/邀请仍由各自服务路由限制到 4 KiB。测试使用超过 4 KiB 的真实 HTTP 上下文，已通过网关直接入口；**代理链路须部署后再测**。
4. 手机在首次落盘前即锁定本轮发送，连点不会趁持久化等待创建第二回合；保存中新增的草稿不被清空。启动与邀请同时读历史时共享一次恢复任务。两个原生回归测试已加入工程且通过类型检查，**未运行，不能声称并发行为在设备上验收通过**。
