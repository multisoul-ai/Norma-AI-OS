## 1. 对象与边界

```text
Workspace
  项目 A 区域 ← 本次两行网格分配的对象
    Agent／Terminal／Browser 卡片 ← 沿用现有排序和排版
  项目 B 区域 ← 本次两行网格分配的对象
    Agent／Terminal／Browser 卡片 ← 沿用现有排序和排版
```

例如 Workspace 有三个项目，项目 A 内有七张 Agent 卡片：外层按三个项目排列，项目 A 内七张卡片仍按原规则排列。项目内部新增、删除、聚焦 Agent 不影响外层项目槽位。

本次仅调整桌面项目总览中的项目区域、外壳间距、Workspace 缩略图中的对应项目区域和导航动画锚点。四分之一规则只适用于总览；展开项目后仍显示完整项目画布。

以下为实施硬边界：

- 不修改 Agent 的顺序、自动排版、默认行列、尺寸策略、拖动换位、主次布局、布局菜单和持久化规则。
- 不增加 Agent 的“两行”预设，不在加载已有项目时强制重排内部卡片，不新增 PTY resize 提交机制。
- 项目布局独立于 Agent 布局配置。项目格子变化只改变真实画布的呈现位置与等比缩放，不写入内部节点 bounds 或 viewport。
- Workspace 首页外层布局、壁纸、主题、iOS、手机协议和工作空间／项目／worktree 归属沿用现状。

## 2. 已确认的项目排列规则

固定两行、至少两列；项目区域等大，宽高随 Workspace 可用区域自适应。采用既有项目顺序，当前存储按 `added_at_unix_ms, id` 返回；从左到右、从上到下填充，打开或选中项目不改变顺序。

| 项目数 | 行 × 列 | 上排项目 | 下排项目 | 单项目面积（未扣间距） |
| --- | --- | --- | --- | --- |
| 0 | 空工作空间 | — | — | — |
| 1 | 2 × 2 | A 空 | 空 空 | 1/4 |
| 2 | 2 × 2 | A B | 空 空 | 1/4 |
| 3 | 2 × 2 | A B | C 空 | 1/4 |
| 4 | 2 × 2 | A B | C D | 1/4 |
| 5 | 2 × 3 | A B C | D E 空 | 1/6 |
| 6 | 2 × 3 | A B C | D E F | 1/6 |
| 7 | 2 × 4 | A B C D | E F G 空 | 1/8 |
| 8 | 2 × 4 | A B C D | E F G H | 1/8 |
| 9–10 | 2 × 5 | 最多 5 个项目 | 其余项目 | 1/10 |
| 11–12 | 2 × 6 | 最多 6 个项目 | 其余项目 | 1/12 |

N 为 Workspace 的项目区域数，与 Agent 数量无关。N > 0 时，列数 C = max(2, ceil(N / 2))；第 i 个项目（从 0 开始）所在行 = floor(i / C)，列 = i % C。N = 0 返回空矩形列表。

空项目、加载中的项目和不可用项目仍占自己的槽位，沿用现有状态与重试入口。空格只显示背景，不生成假项目或额外添加入口。项目再多也扩列、等大缩小到一屏；窄窗仍保持两行，不切为单列滚动。

新增项目按既有顺序追加；移除后保持其他项目的相对顺序。4→5、6→7 等阈值允许项目区域平滑重排，内部 Agent 顺序和矩形不因外层重排改变。

## 3. 实现方案

### 独立项目几何入口

- 保留 `workspace/desktop/layout.rs::project_area_layout(width, height, count)` 为统一适配入口。当前该入口复用了 Agent 主次布局的响应式配置；解除这条配置依赖，不改被复用的原 Agent 配置。
- 在 canvas 域层增加独立项目矩形计算函数：输入项目数量、可用矩形、间距，返回按索引排列的 `Vec<CanvasRect>`。不接收 Agent NodeId，不产生节点重排命令；既有 Agent 网格和主次布局函数保留原语义。
- 复用 `desktop_scene_rect` 扣除窗口与 Dock 安全区。默认项目间距和网格外边距各 8 逻辑 px。区域大小 W×H 时，项目宽 = (W − (C + 1)×g)/C，高 = (H − 3×g)/2。
- 极窄窗口或大量项目时，g = min(8, W/[2×(C+1)], H/6)，确保正尺寸并一屏容纳；不引入导致溢出的最小项目宽度。
- 独立数值基准：1280×800 窗口的内容区原点 (14,36)、大小 1252×673。1–4 个项目时，第一格原点 (22,44)、大小 614×324.5；第二格 (644,44)，第三格 (22,376.5)。

### 总览、缩略图与镜头

- 同步检查 `view`、`workspace_card`、`camera`、`project_switch`、`scene` 的项目几何来源；全部使用同一项目布局结果，不另建缩略图网格。
- 复用原 `project_canvas_rect`、`project_canvas_scene` 和真实 session，在新外壳内等比呈现现有项目画布。可以收紧外壳边距，不能通过改内部节点位置、尺寸、viewport 或拉伸字形硬塞满预览；因原画布比例产生的必要留白保留。
- 项目总览标题条目标高度 28 逻辑 px，名称 13px，更多按钮 20px，预览内边距 8px。极小外壳下收缩标题与边距以避免负尺寸。只调整项目外壳，不调整 Agent 标题、样式和内部间距。
- 空项目整区仍可打开；展开态继续隐藏项目外壳和项目标题条，内部卡片按原规则工作。
- 新网格一屏容纳，项目总览滚动偏移归零；绘制和镜头来源同步归零，消除旧偏移造成的项目离屏。不要修改 Workspace 目录的滚动位置或 Agent 画布 viewport。

### 动画、输入与性能

- 添加／移除项目、系统窗口尺寸改变时才重算项目网格；Agent 的数量、输出和焦点变化不改变外层项目网格。
- 复用现有镜头、场景缓存和帧时钟。项目外壳重排使用既有 330ms 几何曲线；展开／返回继续使用可中断镜头，从实际可见位置转向，不重建会话。
- 项目预览与展开共享真实 session，画布等比缩放；纯项目重排和镜头移动不触发 Agent reflow、节点 bounds 写入或额外 PTY resize。真正改变系统窗口尺寸时，Agent 仍按原有窗口 resize 逻辑处理。
- 同步镜头来源缓存、命中逆变换和裁剪，防止首帧旧锚点、返回边框错位、重复内容和末帧闪跳。沿用减少动态效果设置及既有输入拦截行为。
- 复用 `desktop_motion` 日志，记录项目布局原因、项目数量、行列、区域尺寸与转场结果；不增加逐卡逐帧日志或同步数据库写入。

新增接口仅为独立项目矩形计算函数；没有外部 API、数据库 migration 或手机协议变更。Agent 的 `CanvasLayoutStrategy`、布局菜单、公共排版函数和 PTY 生命周期不因本需求修改。

- 项目数量逐个覆盖 0、1、2、3、4、5、6、7、8、12、31，以及窄窗、4↔5／6↔7 和删除中间项目。断言具体项目坐标、尺寸、空位和边界。

- 采用 `apple-design`、`gpui-styling`、`emil-design-eng`：沿用现有主题玻璃材质与按钮状态；以稳定项目身份、同源矩形维持空间连续性；原型330ms与用户要求优先于技能默认300ms。内部GPUI scene缓存与等比变换复用，减少动态效果直接落定。
