可直接启动的 Goal 任务

Goal 定义

适配 Norma OS 的 Windows x64 核心工作流。 保留现有 Rust、GPUI、域层和 macOS 行为。 使用 GitHub runner 完成构建、测试、真实程序场景及预览包验证。 所有必验项目通过，并交付对应源码版本的程序与证据后，目标才完成。

首版交付项目、画布、终端、文本任务分发、保存和恢复。 Claude 与 Codex 是两个候选 Agent，G1 验证后冻结支持矩阵。 本轮不把普通终端启动算作 Agent 控制完成。

原分期估算仍保留，但本轮不得用分期范围裁剪默认产品构建或禁用能力。 Windows 11 用户设备验收与 Windows ARM64 支持单独记录。 本 Goal 的完成名称为“Windows x64 云端验收预览版”。 它不代表 Windows 11 所有设备能力已经验收。

边界 约定
开发环境 继续在 Mac 修改代码；Windows 特有行为由 runner 验证
主要执行环境 multisoul-ai/Norma-AI-OS 公开仓库，标准 windows-2025 x64 runner
技术版本 保持 rust-toolchain.toml 的 Rust 1.91.1；不直接采用镜像自带 Rust
产品结构 不升级 GPUI，不重写画布、grid 或 Agent 协议，不新建通用平台框架
本次交付 App IPC/图片平台边界、116逐项与Mac16复验；保留VAD、Sherpa、Codex及默认产品能力
后续启动 解决Windows关闭契约与App98条原生边界；收束Mac语言/全局锁隔离

实施时保留工作区已有改动；只提交本 Goal 的完整变更。 任务拆分与平台改动范围沿用 docs/exec-plans/2026-11-01-windows-port-plan.md。

B

Runner 能验证什么

标准 windows-2025 镜像运行 Windows Server 2025。 这与 Windows 11 是两个运行环境，不能合并声明支持状态。 当前镜像包含 Visual Studio、Windows SDK、PowerShell 和 Git。 镜像会更新，每次运行仍须记录实际版本。

本次实测镜像为 win25-vs2026，版本 20261021.278.1。 OS 为 Windows Server 2025 x64，Rust 固定为 1.91.1，Node 为 22.23.4。 进程与活动控制台均在 session 2；存在 1024×768 显示器。 D3D11 设备创建与 WARP 查询均成功，返回 feature level 11.0。 这些环境事实不能单独替代 GPUI 像素和 OS 输入验证。

验证项目 默认环境与方式 通过依据
Rust 构建、单测与集成测试 标准 hosted Windows runner 实际 MSVC 编译、测试退出码与报告
ConPTY、IPC、文件和进程 标准 hosted Windows runner 真实 OS 资源测试，包含失败和清理路径
窗口、渲染和基础交互 先由 G1 探测显示会话、DirectX、窗口与输入 实际程序、可见像素、OS 输入和行为结果
两个真实 Agent 受保护的 Actions 手动验收任务 固定 CLI 版本、真实认证、任务产物及 session 回执
便携包 新的 hosted Windows job，下载同一候选包 无源码构建步骤，解压后真实运行核心场景
macOS 回归 既有 macOS runner；新增差异按需验收 相关测试与真实 App 证据，不破坏现有流程
Windows 11、物理设备和音频 标准 Server runner 不作为最终证据 保持未验收；后续由具备设备的 GitHub runner 覆盖
图形能力是首个环境门槛

不预设 hosted runner 能满足 GPUI 的图形与输入需求。 先运行窗口探针，检查是否有可用桌面和实际渲染。 若失败，记录 ENV_UNSUPPORTED；不能跳过真实窗口验收后宣布目标完成。

若标准 runner 无法承载核心桌面场景，继续完成可独立验证的迁移任务。 桌面验收阶段保持未通过，并提交探针日志和可复现原因。 后续可接入交互式 self-hosted Windows GitHub runner。 该机器须由用户提供或授权，不自动购买、扩容或注册机器。 不能为得到绿色结果，自动改成只编译不验收。

普通 PR 不执行真实模型调用，也不接触发布或用户凭据。 完整验收先通过 workflow_dispatch 指定受信源码版本。 初始工作流可由迁移分支 push 验证。 workflow_dispatch 稳定入口须按正常 PR 流程进入默认分支。

本轮已获用户授权，提交探针到独立分支并触发真实 Actions。 未合并主分支，未修改分支保护，未启用付费 runner。 工作流按路径触发，只有文档更新不会重新跑全部构建。

PR 同分支任务可取消旧运行；正式候选验收串行执行。 固定 Actions 依赖版本，并记录实际镜像版本。 复用仓库钉死的 Rust；先检查 LFS 资源完整性。

后续构建记录磁盘峰值；本轮仅记录各采集任务末尾的可用空间。 本轮关闭增量缓存，编译并发固定为 2，没有上传构建二进制或缓存。 不能靠删除 runner 的系统工具和 SDK 掩盖容量问题。

新 hosted job 仍预装开发工具，不能证明纯净 Windows 11 安装就绪。 另做 DLL 与运行库依赖审计，把用户设备安装验证留在后续矩阵。

真实 Agent 任务需要受保护的凭据与已授权调用预算。 缺少凭据时记 NOT_RUN，不能以协议替身替代 AC05、AC06。 不得从本机复制已有登录凭据到 GitHub。 凭据使用 GitHub Secrets 和受保护环境安全接入。 Fork PR、任意未受信 ref 和可执行测试输入均不得获得凭据。

本轮探针未新增 Secrets，未提交模型任务。 两个 CLI 的安装与启动通过；Codex stdio 初始化返回 Windows 平台结果。 该握手不验证 Norma 的 Unix TUI relay，也不验证真实任务、提问或恢复。

输入法、DPI、多显示器和物理音频只声明实际测到的环境。 Windows 11 专项、Browser 与语音验收仍属于后续阶段。 内容编辑若 G1 无法证明安全保存，首版明确为只读。 该范围变更必须在支持矩阵中冻结，不能运行失败后临时移出必验项。

F

结果判定与交付证据

状态 含义 能否作为必验项通过
PASS 预期行为通过，反向断言及证据完整 能
FAIL 实现、断言、退出码或产物有误 不能
ENV_UNSUPPORTED 图形、桌面、设备或资源条件不具备 不能
NOT_RUN 未执行，或缺少必要认证、预算、依赖 不能
NOT_IN_SCOPE 在执行前已冻结的后续功能 不计入当前必验项，也不宣称支持

未被本轮证据覆盖的阶段与 AC 项保持未开始或未通过。 失败后只重试已判定为暂态的网络或环境问题一次。 断言失败不靠重跑覆盖；每个 attempt 保存独立结果。 阶段只有通过退出门槛才能标记完成。 若 hosted 桌面门槛未通过，整体 Goal 仍未完成。

每次运行输出以下证据；文件路径中的占位符由 run ID 和 attempt 替换：

  • artifacts/windows-acceptance/<run-id>/<attempt>/source-manifest.json：实际 checkout SHA、事件 SHA、workflow SHA、CLI 与工具链版本。
  • artifacts/windows-acceptance/<run-id>/<attempt>/runner-capabilities.json：镜像、OS、GPU、显示会话、输入、截图与可用设备。
  • artifacts/windows-acceptance/<run-id>/<attempt>/acceptance-results.json：AC 编号、状态、耗时、失败类别与证据相对位置。
  • 测试与构建日志：命令、退出码、测试统计和资源峰值。
  • PNG 原图：关键窗口状态与失败现场，不能只有截图哈希。
  • artifacts/windows-acceptance/<run-id>/<attempt>/candidate-manifest.json：包、主程序、helper 的 SHA-256 与构建 features。
  • 对应 SHA 的便携包、功能支持矩阵和已知限制说明。

报告展示通过数、失败数、未执行数和未覆盖数。 工作流上传失败证据；下载后复核哈希和内容。 上传失败或证据缺失时，最终 gate 不能通过。 临时文件、真实用户数据库、凭据和完整模型对话不上传。 测试使用专属数据目录、合成项目和可公开的固定内容。

G

费用、权限与资源控制

当前仓库公开，标准 hosted Windows runner 的计算免费。 该使用量归组织，不消耗个人账号的免费计算额度。 免费计算不代表构建产物和所有 runner 类型都免费。

项目 默认策略
Runner 只使用标准 windows-2025；不启用 larger runner 或 GPU 付费规格
PR 权限 最小只读仓库权限；不传递 Secrets；不使用高权限事件执行不受信代码
Artifact 留存 预检小报告 7 天；截图和验收日志 3 天；便携包默认 1 天
Artifact 容量 本 Goal 当前保留数据控制在约 350 MiB 内；组织 Free 500 MB 为共享额度
缓存 复用现有 Rust 缓存；不提高每仓库 10 GB 的免费缓存上限
并发与超时 按阶段限时；正式候选验收串行；临时环境失败最多重试一次
真实模型调用 只在用户已配置凭据和预算的受保护验收任务执行
签名与正式发布 当前只交付 CI 预览包；不购买证书、不发布 Release、不更改账单设置

每次大包上传前盘点当前仓库留存量。 组织其他仓库也会共享产物存储，需在阶段验收时核对账单页。 空间不足时停止新增大包，不删除其他任务的验收记录。 可回收本 Goal 明确过期的自有产物，保留当前候选的完整证据。 免费计算不能作为所有用量都不会产生费用的证明。
