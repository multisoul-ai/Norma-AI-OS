# iOS 工作空间实时活动：默认总览与验收

更新：2026-10-06。默认登记与总览修复已实现，推送通道尚未发布。物理 iPhone 11 仍为 `unavailable`，真机后台自动启动未验证。

## 默认行为

- iOS 对全部已配对 Mac 自动登记，不要求选择工作空间或开启跟踪。每台 Mac 一张活动，汇总该手机已获授权的全部工作空间；新配对、App 启动、系统权限变化、token 轮换都会同步。普通通知开关不参与活动登记。
- Mac 从保留的项目会话、卡片/审批事实及持久交付生成摘要。先合并全部工作空间，再按审批、失败、验收、执行排序并截取三行；同类保持目录顺序。重复投影的同一次 Agent 运行只计算一次。
- 每行保留真实工作空间、项目区域、具名 Agent、当前动作和介入原因。计划步骤属于原 Agent，不合成项目百分比；仅真实完成、冻结、可读取、无冲突且未验收的交付进入验收队列。
- 没有运行 Agent 但仍有待处理项时保留活动。全部处理后结束，结果保留十分钟；30 秒合并普通变化、60 秒保活、120 秒过期，关键事项立即更新，连续八小时不自动循环。
- 用户滑掉本轮后不立即重启；Mac 观察真实空闲后，原子清除本轮抑制与旧更新 token，下一次工作才重新启动。系统不允许实时活动时不创建新登记，既有登记停止自动启动并清除 token。
- iOS 17.2 起使用 push-to-start；17.0/17.1 在前台自动创建活动，之后用活动 token 更新。Apple 的系统开关与权限仍须尊重，默认开启不能覆盖系统禁止。

## 复用与兼容

- `WorkspaceActivitySummary`、APNs 服务、授权、事项去重、订阅版本和周期水位继续复用。登记不绑定空间时表示 Mac 总览；旧指定空间登记仍能解码，手机同步时迁移为默认总览。
- `summary/subscription/set_subscription` 可省略空间；详情、审批、验收和操作回执必须定位实际空间。局域网与加密中继都经过相同请求校验，不能通过总览扩大原项目授权。
- 全局摘要每行携带真实空间 ID/name。项目点击进入对应空间/区域，回源核验后操作；卡片整体和灵动岛打开收件箱。身份、原目标或权限变化会阻止旧操作。
- 登记写入先保存本地 generation；响应丢失只读取原状态，不重放写入。忘记电脑时立即清除本地登记并结束活动，凭据在删除前仅捕获于内存；远端清理排在在途登记之后，迟到回复不能重新开启。离线清理失败仍需在 Mac 撤销此手机授权。
- Mac 的目录/存储读取、冻结成果读取、网络发送和回源等待均在后台。捕获不完整时不发送假空闲。发送前重新核验授权目录和订阅版本。
- 普通进度只更新活动；审批、失败、可验收成果在普通通知已启用时沿原管线提醒并按事项去重。远程 start 有一次系统提示，update 无 alert/sound，完成卡片不伪造成果通知。

## 尚未完成的上线条件

当前推送服务是部署者配置 relay 地址与访问凭据的私有服务。手机端默认登记已经消除跟踪配置，但全新 Mac 安装的完全零配置仍缺平台自动下发服务配置：应通过已有认证/配对渠道下发部署端的地址、环境与设备授权，不能把共享 relay 密钥写死进客户端。本轮没有新增公共多租户服务，也没有部署或伪造可用推送配置。

目前证据是本地服务协议接受与模拟器 ActivityKit 实际展示；没有新活动经线上服务或 Apple 接受的证据。连接可用 iPhone 后还须验证：

1. 已配对 Mac 开始工作时，App 在后台/未运行也自动出现，普通通知关闭仍有效；分开记录服务/APNs 接受与设备实际展示，关联 event/cycle ID。
2. 启动与更新 token、轮换、重启、重复启动抑制、多 Mac 独立、系统权限撤销。
3. 断网两分钟过期、恢复更新、审批/失败/验收立即更新；点击逐项目回源核验，迟到目标与丢响应处理。
4. 事项全部处理后结束、十分钟结果保留、滑掉本轮后的空闲恢复、八小时不循环。

真机全部通过后才部署推送服务，必须同时发布 `relay.mjs` 与 `activity.mjs`。旧普通通知的 accepted 回执不作为新实时活动验收证据。
