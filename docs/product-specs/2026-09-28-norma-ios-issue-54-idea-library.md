# #54｜独立想法库实施规格

状态：实现中 · 2026-09-28。依据 [Goal](../exec-plans/2026-09-28-norma-ios-issues-01-05-native-goal.md)、[逐屏验收](2026-09-28-norma-ios-prototype-fidelity-acceptance.md)、[P01](norma-ios-ideas-workspaces-2026-09-28/P01-idea-library.png)、[P02](norma-ios-ideas-workspaces-2026-09-28/P02-voice-idea.png) 与 GitHub #54。

## 用户流程与边界

1. 从现有 App 的明确入口打开「想法库」；未连接 Mac 及断网时仍可新建文字想法。保存成功才显示「已记录」，返回列表即可看到，重启后仍在。空白正文不可保存；落盘失败时保留编辑内容并显示错误。
2. 搜索正文和原始转写，可打开想法继续编辑。编辑只更新该想法和修改时间，不创建 Workspace、项目、线程或任务，不访问 Mac 与云端。
3. 语音页在用户点按录音后请求麦克风与系统语音识别权限；麦克风被拒绝时不能启动录音，页面说明恢复路径。Apple Speech 优先设备端识别；设备端不可用且系统在线识别可用时使用 Apple 在线识别。音频录在 App 私有目录，实时显示转写且可编辑。
4. 停止录音或保存时，原始音频、时长和用户文字一起落盘。识别失败、断网或没有转写结果时，仍允许保存为「待转写」并显示重试入口；录音在重启后可播放和重新转写。语音想法既不自动派工，也不自动加入 Workspace。
5. UI 与 [P01/P02](2026-09-28-norma-ios-prototype-fidelity-acceptance.md) 的信息顺序、字号、间距、卡片、颜色、主按钮、波形及反馈对齐。原型机身、假状态栏不进入 App；系统 Sheet/导航使用可用 SDK 的原生材质，iOS 17–25 回退到系统材质。支持动态字号、VoiceOver、减少动态效果和键盘安全区。

## 存储契约

- iPhone App 私有目录持有 SQLite `ideas.sqlite` 和 `IdeaRecordings/<idea-id>.caf`。想法 ID 为独立 UUID 字符串，不借用旧协议代表 Mac 项目的 `workspace_id`。每条记录含类型、正文、原始识别结果、转写状态、可选录音文件名/时长、创建与修改时间；不含 Workspace ID。
- `text` 记录必须有非空正文且没有录音；`voice` 记录必须有原始录音，可以暂时无文字。转写状态为「待转写／已完成／失败」；进行中的 UI 状态不作为已完成落盘。
- SQLite 提交成功才报告保存成功。写入失败不能清空编辑页；损坏数据库不能当空库覆盖。录音移动到私有目录后如果数据库提交失败，原音频仍留在设备上供恢复或再次保存，不能静默丢弃。
- 正文按本机用户输入原样保存；搜索只返回匹配项，按修改时间倒序。重新转写仅在用户尚未编辑正文时写入正文，避免覆盖用户修改；原始识别结果独立保存。
- 首版不做云同步、跨设备恢复或自动导入旧实时通话记录。删除想法时须经明确操作，不因移除 Workspace 关联而删除。

## P02 动效与编辑状态（2026-09-30）

按用户对当前原生页面的动效要求，参考 `apple-design`、`emil-design-eng`，并由 `review-animations` 复核。保持 P02 的构图和实底阅读面；动画只影响视觉反馈，不延迟录音、取消、保存或键盘操作。

| 状态 | 原生交互与动画 | 验收 |
|---|---|---|
| 进入页面 | 波形、正文卡、录音入口以 220ms 淡入与小幅位移/缩放进入，组间错开 40ms，总长不超过 300ms | 真实模拟器录屏；进入途中仍可关闭 |
| 等待录音 | 麦克风外圈缓慢、轻微呼吸；波形不模拟说话，文字仍为「等待录音」 | 尚未点录音不请求麦克风、不产生音频；UI 标签与计时保持待机 |
| 录音中 | 波形由采集器现有 10Hz 真实电平驱动，使用固定布局上的缩放插值；按钮切换停止图标，外圈给出录音状态反馈 | 原生视图高/低电平渲染不同；真实麦克风效果仍由用户真机验收 |
| 按压与状态 | 按下 100ms 小幅收缩，松开 250ms 弹回；准备中显示系统进度控件，状态文字淡变 | 动画不阻塞按钮，停止后不残留录音波形活动 |
| 编辑/后台/减少动态效果 | 编辑与后台停止呼吸；减少动态效果下只保留短淡入和颜色反馈，不位移、不缩放、不按音量跳动 | 系统偏好与真实页面复核，渲染测试覆盖静态波形 |
| 未保存退出 | 原生 Alert 同时显示「继续编辑」与「放弃文字/录音」；返回、关闭共用同一保护 | 取消保留原文；明确放弃返回列表且不显示「已记录」 |

键盘出现和大字号时，顶部退出入口与编辑操作必须仍可达，聚焦的正文自动对齐到可见内容区；最大辅助字号下至少两行输入文字完整位于键盘上方。滚动和系统键盘转场保持原生行为，不为逐字输入加动画。
