# #57｜Workspace 工作线程、长期消息与工作简报

状态：实施中，不能作为验收完成证明。依据 01–05 Goal、原生架构、数据存储矩阵及 P05/W04/W05；2026-09-29。

## 用户闭环

1. Workspace 可有多个线程。用户从 Workspace 新建，或在已保存想法的菜单选择「在工作空间推进」，选择已有 Workspace、填写线程标题后创建。保存想法本身不创建线程。
2. 来源想法继续留在独立想法库。线程保存原想法 ID 和引用时的文字快照；以后编辑想法不静默改写线程历史。来源卡可回看引用原文，也可打开当前想法。
3. P05 承载群聊。每条消息有稳定 ID、线程 ID、来源设备、作者、正文、时间和同步状态，先落盘再显示已保存；两个线程不串消息，Norma 私聊不自动复制到线程。离线消息明确显示「待发送」，不会显示 Agent 已接收。
4. W05 工作简报显示当前线程目标、Workspace 项目、共同事实和决定。修订记录原文、版本、修改者、时间及来源消息；来源消息必须属于同一 Workspace。目标只改变当前线程，共同事实/决定可被同 Workspace 其他线程查看。没有硬约束模块。
5. 归档 Workspace 保留线程与历史；重开后原 ID 与消息不变。关联项目移除不删除线程或改写既有来源。当前阶段不提供永久删除。

## 数据与依赖

复用 `CollaborationWorkspaceStore` 的本机 SQLite，扩充线程、消息、事实版本表与本机来源 ID；不再引入另一套数据库封装。Workspace 外键、消息唯一 ID 与事实版本唯一键由 SQLite 守住。原有配对、想法与私聊文件保留。

| 对象 | 身份与保存内容 | 约束 |
|---|---|---|
| WorkThread | UUID、Workspace ID、标题、来源想法 ID/引用快照、本机来源 ID、创建时间 | 创建时 Workspace 必须存在且未归档；一个线程只有一个 Workspace；当前切片不提供线程改名 |
| WorkThreadMessage | 稳定 UUID、线程/Workspace ID、作者、本机来源 ID、正文、时间、待发送状态 | 空白消息拒绝；重试同一 ID 同一内容只保留一条，冲突内容拒绝；归档空间不接收新消息 |
| WorkspaceFact | 稳定 UUID + 递增版本、类别、Workspace/来源线程 ID、正文、作者、来源消息 ID 或明确手动编辑、时间 | 目标按线程过滤，事实/决定在 Workspace 内共享；跨 Workspace 引用拒绝；修订须提供当前版本，旧版本不得覆盖新版本 |

本轮先交付可运行的本机线程与简报，所有尚无 Mac 回执的消息仍是待发送。#59 负责真实派工；#61 的跨 Mac/桌面同步不在本轮伪造。#57 的离线重连验收必须在对应真实传输接入后核对，不能凭本机唯一键或占位回执关闭该门槛。

## 验收映射

- 单测先失败：想法引用不移动原件；同一 Workspace 两线程隔离；另一 Workspace 无消息/共同事实；重启保留来源和历史；消息重复去重、冲突拒绝；事实修订版本、来源检查、归档拒绝写入。
- 原生 UI：从想法与 Workspace 分别建线程，输入消息、重启查看、修改目标与决定、回看来源，返回保持原页面；消息无真实回执时不得出现「执行中／已接收／完成」。
- P03 增加真实线程预览和成员；P05 还原标题、状态、简报/来源卡和消息输入；W05 还原目标/项目/决定层级。任务和成果组件仅以隔离视觉数据验收，不混入正式存储。
- Computer Use、独立只读 UI 复核、动态字号/键盘/VoiceOver 及真实同步证据缺一不可；缺失保持进行中。

## 草稿补全（09-29 本地开发接续）

- 输入草稿按线程 ID 在同一 SQLite 的 `work_thread_drafts` 表保存 `{text, revision}`，与正式消息分开；不修剪输入中的空白或换行。页面重读不覆盖内存新编辑，重启读取已保存版本。
- 每次实际编辑生成新 revision。发送前捕获该版本；追加消息与清理匹配版本的草稿在同一事务完成。后来改回相同文字也算新版本，不被旧发送清空。
- 逐线程写入、合并快速输入、独立错误与重试。超出 100,000 字的草稿保留在原输入框并明确提示，其他线程仍可保存和发送；切到后台申请短暂系统时间完成已排队写入。
- 新增 Core 回归覆盖重启、原子清理、同文新版本和错误隔离；原生模型/UI 用例也已补齐，执行状态见[本地联调记录](../exec-plans/2026-09-29-norma-ios-local-test.md)。当前消息仍无真实 Mac 回执，保持待发送。
