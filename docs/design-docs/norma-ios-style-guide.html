01 / ETHOS

视觉原则

从参考原型提取可复用的界面决定，让每个页面回答：我在哪里、正在发生什么、接下来能做什么。

01

工作先于装饰

首屏先呈现事项、状态与下一步；Norma 角色只在通话和引导中成为主视觉。

02

色彩解释状态

蓝色负责操作，薄荷提示积极状态，粉色提示待处理，黄色提示限制。

03

实底承载内容

对话、任务和证据保持稳定对比；玻璃留给导航、底栏、输入与 Sheet。

04

一个主要行动

同屏最强操作只有一个，其余操作清楚、可达、不会和危险行为混淆。

05

随时可接管

返回保留上下文，Sheet 跟手；任务、终端输入权与验收结果始终可见。

06 / REVIEW

交付前检查

HTML 是视觉速览，完整规则、冲突优先级与真实 App 验收要求以 Markdown 规范和逐屏验收文件为准。

  • 相同机型、字号、外观与内容下对照原型和真实 App 截图
  • 长内容保持实底；玻璃仅用于功能层
  • 状态既有色彩，也有文字或图标
  • Dynamic Type、VoiceOver、键盘与安全区可用
  • 主要触控目标至少 44 pt，并有按下/选中/禁用反馈
  • 减少动态效果与减少透明度均有明确替代表现
