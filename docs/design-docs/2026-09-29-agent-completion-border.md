# Agent 完成提示边框

未读的 `Done` 卡片沿用现有冷色呼吸相位：2px 描边显示色相变化，描边外侧的三层透明圆角环形成约 8px 柔光。首次进入未读完成态时，柔光在 520ms 内从最多 11px 收回常态；之后随呼吸相位改变亮度。圆角环的内边缘不进入卡片，填充、标题栏和基础阴影不接收呼吸色；聚焦时也不叠加以呼吸色着色的整卡阴影。已查看后描边和柔光淡出，恢复常规卡片视觉。

设计参考：`apple-design` 的内容优先、清晰层级与减少动态效果；`emil-design-eng` 的状态反馈和动效频率原则。一次性亮起表达“刚完成”，持续呼吸表达“尚未查看”；减少动态效果时不播放脉冲。GPUI 0.2.2 复用现有呼吸相位与动画循环，用透明填充的圆角环在卡片外侧绘制柔光。

验收：`motion_tests` 验证亮起、持续呼吸和淡出；`border_glow` 测试验证各层圆角环完全位于卡片外侧；`chrome` 测试验证聚焦时不产生彩色整卡阴影；`e2e_05_agent_border` 验证 `Done → 未读 → 已查看` 流程；真实 App 检查文字区域不被特效染色。
