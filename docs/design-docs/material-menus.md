# 菜单与选择器：Google Material 设计偏好

用户于 2026-10-05 明确要求以 Google 的设计哲学改进菜单。该偏好优先于菜单原有的 Apple 视觉基线；macOS 的键盘和窗口行为继续遵守平台约定，其他页面沿用原有基线。

参考官方 [Material 3 菜单指南](https://m3.material.io/components/menus/guidelines)与[菜单规格](https://m3.material.io/components/menus/specs)：菜单是由触发器展开的临时表面；长列表可搜索、可滚动；选项保持单一操作，颜色和状态层帮助辨认层级与选择。

## 设计原则

- 渐进展示：收起态显示当前值与展开图标；搜索与完整目录只在展开时出现。避免常驻的大型列表、重复的“当前/已选”文案和多层卡片。
- 排版与密度：主名称、辅助信息分层，使用 4/8px 间距节奏；菜单项采用 48px 高度、12px 水平内边距和元素间距。规格的 dp 转为桌面逻辑 px，按实际可读性验收。
- 表面与颜色：统一圆角与轻阴影，用不透明表面确保内容可读；复用 Norma 的语义主题色，克制使用强调色。无需照搬 Google 品牌蓝或引入额外色彩体系。
- 状态明确：hover、pressed、keyboard focus 与已选状态都有反馈；右侧勾选表示已保存值，浏览高亮表示确认目标。键盘浏览和取消不能改变设置。
- 直接操作：点击、Enter/Space/↓ 打开并聚焦搜索，↑/↓ 浏览，Enter 确认，Escape、Tab/Shift-Tab 或点击外部关闭；键盘确认与取消返回触发器焦点。长目录保持可滚动，空搜索结果明确反馈。
- 复用组件：优先 `ui::component` 的 Button、Popover、List 和 Input，按项目钉死的版本验证 API；有具体的选择状态需求时可定制目录行，避免重写弹层和导航基础设施。

## 豆包音色选择器的落地与验收

参考 `apple-design` 的平台习惯与可访问性、`emil-design-eng` 的触发源与反馈原则，以及 `gpui-elements`、`gpui-styling`、`gpui-entities`、`gpui-actions` 的实现方式。菜单视觉遵循上述 Google 偏好；高频搜索和键盘导航保持即时，不添加装饰动效。

采用 320px 紧凑选择字段与 400px 搜索浮层，窗口较小时限制宽度；48px 双行选项显示名称与语言，独立勾选和浏览高亮，完整目录通过组件虚拟列表展示。浮层与触发器右侧对齐，内容高度固定为 328px（40px 搜索 + 6 × 48px 选项），小窗口时限制高度，防止过滤结果变化导致搜索框跳动。选择仍后台保存、下次通话生效；每次打开重置搜索并定位当前音色。

验收映射：过滤后的确认目标、空结果、清空目录、搜索不改变已选值，以及真实搜索 Input 的 Tab/Shift-Tab 取消和焦点恢复由聚焦单元测试覆盖；收起布局、浮层定位、浅/深主题的 hover/pressed/focus/selected、键盘与鼠标选择、关闭与重开、重启后保留选择由真实 App 的 Computer Use 覆盖。测试与截图记录见 [`doubao-voices.md`](../references/doubao-voices.md)。
