# Ideas Vault 原型图片生成提示词

以下为本原型包使用的最终提示词集合。所有图片均使用内置图片生成模式，并以现有 `docs/design-docs/core-ui-v2/canvas.png` 作为 Norma OS 视觉参考；后续图片同时参考已经生成的 Ideas Vault 设计稿，以维持视觉一致性。

## 共同视觉约束

```text
使用场景：ui-mockup 或 infographic-diagram
画布：16:9 横向 macOS 产品设计稿
视觉：现有 Norma OS 无限画布、半透明浮动卡片、暖白材料、graphite 文本、蓝紫主色、mint 成功色、系统字体、克制阴影
质量：可实现的高保真产品 UI，不是概念艺术
交互：hover、focus、selected、disabled、loading、success、warning、error 状态必须可区分
边界：复用 Agent、Preview、Browser；不展示新增永久节点类型
禁止：Mermaid、水印、移动端框架、暗黑赛博风、无关图表、占位乱码
```

## 00 — 端到端交互总览

```text
创建 “Norma OS / Ideas Vault · 想法库” 的端到端交互总览板。

主流程按从左到右七步展示：
1. “自然语言捕获”——用户说“Norma，记一下这个想法：让语音输入显示实时意图。”
2. “识别并结构化”——标题、原始记录、建议标签“语音输入”“交互”、状态“草稿”
3. “可靠保存”——“正在保存…”到“已保存 IV-2026-0042”

5. “补充素材”——“添加文件”“关联 Preview”“保存网页链接”“添加视频”

“可能重复 → 查看已有 / 仍然保存”
```

## 04 — 异常、恢复与生命周期

```text
创建 4×2 的状态矩阵，每格展示触发、用户可见反馈、操作和结果：

R1 可能重复——“查看已有”“仍然保存”；用户决定，不自动合并。
R2 保存失败——“重试”“复制原文”；未成功前不返回 Idea ID。
R3 保存中取消——“继续编辑”“放弃本次捕获”；无半成品记录。
R4 立即撤销——“恢复”“查看最近删除”；可逆，不硬删除。
R5 附件部分失败——“重试失败项”“保留外部链接”；主记录不回滚。
R6 外部文件移动——“重新定位”“复制到 Vault”；修复引用，不丢元数据。
R7 归档与恢复——“撤销”“移至草稿”；从默认列表隐藏，可检索。
R8 无结果——“清除筛选”“让 Norma 搜索”；不自动新建。

底部生命周期：
“草稿 → 待评审 → 已采纳”
“草稿 → 暂存”
“任意非删除状态 → 已归档 → 恢复到原状态”
“撤销保存 → 最近删除 → 恢复 / 30 天后清理”

原则横幅：“所有破坏性动作可撤销 · 真实落盘后才确认成功 · 原始输入始终保留”。
```
