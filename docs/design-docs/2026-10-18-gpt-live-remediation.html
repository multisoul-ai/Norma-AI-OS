用户要得到什么

实时说话，就能创建智能体卡片并操作项目

使用 GPT-Live 实时对话，语音提出请求后，画布实际发生对应操作，GPT 根据真实结果回复。对话保持连接，后续可以继续下发任务、查询状态和插话。

用户动作 必须出现的结果
说“帮我创建一个 Codex 智能体卡片” 当前项目出现一张正确类型的卡片，返回真实 node ID
继续向该智能体下发任务 任务进入项目原有任务系统，回传真实接收状态
询问卡片或任务状态 读取项目实际状态，再通过语音回答
一边执行一边继续对话 音频收发继续；工具执行放在后台
更正、取消或重新连接 未提交请求能撤销；已执行操作可核对，避免重复创建

整个过程保持 GPT-Live 对话，工具操作直接在语音流程内完成。支持实时对话，也支持用户选择按住 Cmd+E 说话。

名称 实际含义 创建卡片时做什么

LiveBridge 本身不调用模型。NormaSession 是代码类型，其内部会调用后台模型；用户无需另外创建一个名叫 Norma 的智能体卡片。

当前 GPT 分支已经创建独立的 NormaSession 实例。整改沿用该隔离方式，由 GPT 路径负责配置、输入控制、提示词和调度。

GPT 实时交互怎样验收

动作 GPT 实时对话 GPT 按住说话
Cmd+E 开始或结束 Live 对话 会话就绪后按住输入真实声音
松开 E 或 Cmd 保持实时对话 收口本次输入，保持连接等待回复
工具执行中 双工音频继续，可继续对话 继续接收回复，可开始下一次输入
用户主动静音 保持静音 按键不覆盖静音选择
失去焦点 保持明确的通话状态及结束入口 收口本次按住输入，避免持续误收音
冷启动未完成就松键 不适用 撤销本次输入；迟到回调不得开启麦克风

工具执行前重验项目、会话代次、原话授权和最新版本。按住模式需确认本次输入已释放；实时模式结合说话状态及转写版本判断。松键和 ACK 都不代表转写已经完整。

GPT 松键后继续发送协议要求的静音帧，不上传按键区间外的真实麦克风声音。松键只结束本次输入，已建立的会话保持到显式结束。已采尾音排空，并确认 transport 完成发送后，才恢复工具调度。此确认不是云端转写完成证明。

首版不新增空闲倒计时或自动挂断设置。对话入口持续显示连接状态和结束操作；静音及等待期间仍可能产生 Live 用量。

VAD 失败时聊天仍可继续，Live 委派的项目工具暂停，并显示重连重试提示。设置中的操作核对仍可只读查看本地回执。

切换服务沿用现有入口。GPT 的迟到回调按原会话身份处理，不得改变新会话状态。
