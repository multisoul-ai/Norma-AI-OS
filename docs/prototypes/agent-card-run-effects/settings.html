设计说明
  • 位置:设置 → 通用 → 特效,放在已有“派发特效”分区之后;同一页、同一套结构(当前大预览 → 风格库网格 → 行为),用户不用学新布局。
  • 大预览默认自动轮播六个状态,下方状态芯片带进度条;点某个状态即固定在该状态,点“自动”恢复轮播。切换状态时颜色与强度从当前值平滑过去,演示真实的可中断表现。点击预览卡 = 标记已查看。
  • 风格库按“极简 / 表现力”两组:静止时是定格帧并显示“预览”提示,悬停或键盘聚焦才循环播放;点击、回车或空格立即生效,Snackbar 提供撤销。方向键在组内移动焦点。
  • 减少动态效果时:风格库不自动播放;大预览仍随状态变色(颜色变化不算动效)。
  • GPUI 落地:在 crates/app/src/settings/effects/ 新增 run_style.rs(分区)与预览复用 motion/run_style 的纯函数;网格列数复用 WallpaperLayout;偏好键 agent_card.run_style,默认 classic,保存走后台线程。
