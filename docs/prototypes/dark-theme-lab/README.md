# 深色材质选色室

状态：用户已选定月岩、深海石，分别替换 App 的午夜紫、森林薄荷。入口 `index.html` 标注最终选择，其余候选保留供对照。

用户认为午夜紫与森林薄荷不好看，要求重新设计候选并同步原型。五个方案保持同一套桌面布局，差异集中在底色温度、提升层亮度、正文色温与强调色饱和度。没有通过改布局来制造差异。

| 候选 | 方向 | 适合 | 取舍 |
| --- | --- | --- | --- |
| 月岩 | 中性矿物黑、银灰微紫 | 喜欢墨黑但想留一点紫 | 紫色存在感弱 |
| 烟梅 | 暖乌梅黑、玫瑰灰 | 偏爱温润的紫色 | 带粉紫倾向 |
| 苔墨 | 哑光橄榄黑、鼠尾草 | 喜欢自然沉静的绿 | 略偏黄调 |
| 深海石 | 蓝黑、磨砂灰青 | 希望与地球壁纸协调 | 冷蓝气质更强 |
| 赤铜 | 焦茶黑、柔铜、米白 | 想离开紫绿、尝试冷暖对比 | 装饰感更明显 |

Apple 设计原则落地：保留空间关系和系统字体，文字独立于半透明材质，强调色集中用于选中、焦点与少量提示。每个候选包含工作画布、左右抽屉、两个终端和工作空间起始页；可操作输入、分段、工具、工作空间搜索与原型内新建。

顶部固定选择器遵循本仓库 prototype skill；因为工作画布含底部 Dock，使用其允许的顶部位置。1–5 与方向键可切主题，编辑输入时不拦截按键。URL 保存当前候选；收藏使用本地存储，不会发给 Agent，用户仍需告知最终名称。

## 材质与对照边界

- 默认壁纸逐字节内嵌自 `crates/app/assets/home/earth-horizon.png`，不改色。
- 抽屉主蒙层统一为 60% 不透明度。浏览器 backdrop blur 为 24px；这不是 GPUI 最终合成的保证。
- 五个新候选终端阅读底层统一为 97%；原紫、原绿对照保留代码中的 214/255 终端底层。
- 原版对照使用既有主题颜色做 HTML 模拟，未冒充真实 App 截图。
- `artifacts/dark-theme-comparison/palette-preview.html` 已指向此页；六主题截图页与 70%/60% 对照页均增加候选入口，历史截图未改动。
- App 实现使用选定候选的语义色值；实际 GPUI 结果以真实 App desktop-e2e 证据为准。

## 原型验证

使用 `docs/prototypes/package.json` 中已有的 Playwright 依赖：

```sh
node docs/prototypes/dark-theme-lab/check.cjs
```

在独立工作树没有安装该依赖时，可用 `NODE_PATH` 指向已安装的 `docs/prototypes/node_modules`，不修改产品依赖。

检查五个候选 × 两个场景、壁纸解码、原版对照、分段选中、输入禁用与提交、焦点、悬停、按住、工具返回、收藏持久化、快捷键、无效 URL 回退、390px 宽度和 1:1 模式。截图与结果保存到 `artifacts/theme-candidates/`。测试只声明 HTML 原型行为，不声明真实 App 验收。

过程记录：初次截图发现大于浏览器 CSS 自定义属性限制的内嵌壁纸被丢弃，已改用原图 `<img>` 背景，并加入图像加载断言；一次 1:1 检查早于下一帧布局，已等待实际缩放落定。最终结果以 `artifacts/theme-candidates/check-result.json` 为准。
