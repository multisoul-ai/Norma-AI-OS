# Norma 底部工作抽屉

独立 HTML 交互原型。基于 2026-11-04 提供的真实 Norma App 截图，还原顶部工作空间／项目导航、半透明终端卡片、默认 `norma-awake.mp4` 视频以及底部 Canvas Dock。只替换工作入口的交互，不修改正式 Rust App。

## 体验

从本目录 `index.html` 打开，或通过仓库 HTTP 服务访问。URL 加 `?open=1` 可直接查看抽屉。

- 点击底部指令栏中的 Norma，抽屉从底部向上展开。收起按钮、再次点击 Dock、Escape 均可收起。
- 页面获得焦点时，`⌘E`（或 `Ctrl+E`）立即开关抽屉。此处沿用现有 Norma 对话入口的快捷键；没有注册 macOS 系统全局快捷键。
- 左侧按“需要你／处理中／等待中／已完成”分组。右上角搜索工作空间与项目。小窗口先展示对话，通过左上返回键查看任务列表。
- 选中任务后，右侧直接回复对应 Agent；原型的画布卡片和抽屉共用消息与草稿。
- 点击右上定位按钮，进入原画布卡片。通过“返回 Norma”回到同一任务、筛选范围、列表滚动位置和草稿。
- 采用建议只推进执行；验收后进入待合并。已完成卡片仍可以继续讨论。
- 新任务在明确工作空间和项目后，进入等待拆解；不会伪造已派工的 Agent 卡片。
- 支持中英文、浅色／深色、暂停视频、减少动态效果、模拟新进展。

## 关系与边界

查看范围为桌面工作空间及其项目区域；同一个项目在不同空间中的 Agent 卡片和会话独立。消息状态键由工作空间 ID、项目区域身份、卡片 ID 和会话 ID 共同组成，不能用 Agent 名称或项目名代替。

示例中 Norma OS 和实验室都有 Norma-AI-OS / Grace；切换后不会串消息。原型只保留当前页面生命周期中的本地状态，刷新会重置。Grace、Iris、Jasper、Kevin、Henry 的文字根据参考图组织，用于展示交互，不读取实时 Agent 状态，不发送真实 Agent 消息，不执行建议、不合并 PR。Norma 的推荐与 Agent 的会话发言分别署名。

正式接入时，应复用已存在的项目 Runtime、卡片和会话路由；底部入口与快捷键都调用同一个展示动作。全局系统快捷键、真实流式会话、持久化和终端输入适配不在本原型范围内。

## 设计落地

- Apple 空间一致性：抽屉沿同一方向展开与收起，保留原画布背景，定位返回恢复视角。
- Apple 材质层级：沿用当前视频及终端材质，抽屉采用更实的深色表面保证长文字可读，细边线区分任务与对话。
- 动效技能：点击开关使用 240ms `--ease-drawer` 的 transform 过渡；支持中途反向。键盘开关无动画；减少动态效果时暂停视频并移除位移动效。
- 原生 HTML dialog 提供焦点约束与 Escape；选择器使用原生 popover、搜索和方向键。无需额外前端依赖。
- 状态反馈包含 hover、pressed、focus、selected 和 disabled。

## 验收

测试集中在 `tests/flows.spec.cjs`：

1. 底部入口、收起、快捷键恢复同一会话。
2. 项目筛选与同名跨空间卡片的草稿隔离。
3. 抽屉和画布共享会话、定位和视角恢复。
4. 决定对应正确阶段，新事件不切走当前工作。
5. 创建任务必须明确项目，等待拆解时不可伪装成现有卡片。
6. 中英文、1024 / 768 / 390px 和减少动态效果。
7. 列表滚动恢复、原生焦点约束、快速反向开关。
8. 已完成卡片继续沟通，标签输入只作为文本展示。

通过独立 Chrome Playwright 验收；`tests/capture.cjs` 生成画布、展开抽屉、原卡片会话、英文、浅色和窄窗口截图。图片均在 `assets/`。这是浏览器原型验收，不是原生 macOS App 的 desktop-e2e。

## Material 交互调整

根据用户最新要求，抽屉内的交互以 Google Material 为基线；保留原画布、视频、Dock 与 macOS 键盘习惯。规范来源是项目的 `docs/design-docs/material-menus.md` 与 `docs/quality/ui-interaction-feedback.md`，对应 Material 3 的菜单、筛选、按钮层级与状态反馈原则。

- 渐进展示：工作空间／项目使用紧凑触发器与临时搜索浮层，48px 双行选项；没有匹配项时给出空态。
- 选择和浏览分离：勾选表示已确认范围，描边表示键盘当前目标。方向键仅浏览，Enter 才确认，Escape 或 Tab 取消且恢复触发器焦点。取消菜单不会连带关闭抽屉。
- 直接筛选：列表增加任务／Agent／项目搜索，以及带数量的状态筛选 Chip。搜索只改变列表；右侧当前会话继续保留，若被过滤掉则提供“显示当前工作”。
- 清晰操作：主要推荐使用 filled button；“修改后发送”使用次级文字按钮；“定位卡片”使用带标签的 outlined button。输入为空时发送按钮禁用。
- 独立状态层：浅深主题分别提供 hover、pressed、keyboard focus、selected 与 disabled；当前任务采用 tonal surface 和勾选，避免把焦点当成选中。
- 连续反馈：发送、采用建议、创建与新进展使用 Snackbar；“查看”由用户明确触发，更新不会自动切走当前任务。提示支持关闭，指针悬停、键盘聚焦及切入后台时暂停计时。这里不对已发送指令提供虚假的撤销能力。
- 可见焦点：窄窗口切到会话后聚焦可见标题，不把焦点留在隐藏的列表里。原有共享草稿、画布定位、返回现场及快捷键行为保持。

新增 `tests/material.spec.cjs` 的五项聚焦验收：菜单提交边界、筛选与草稿、键盘及通知操作、双主题状态层与尺寸稳定、窄窗口焦点。和原有八项流程共 13 项浏览器验收。新增截图 `assets/material-menu.png` 与 `assets/material-feedback.png` 展示选择与反馈。
