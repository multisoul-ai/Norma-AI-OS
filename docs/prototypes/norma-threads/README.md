# Norma 项目频道与任务线程原型

本轮落实“项目频道 + 任务线程 + 全局进度”。沿用 `norma-super-agent` 原型的默认视频、示例工作、决策与画布定位逻辑，重新组织沟通入口。正式 App 未修改。

## 打开

在仓库 / worktree 根目录启动静态服务：

```bash
python3 -m http.server 8745 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8745/docs/prototypes/norma-threads/`。也可直接打开本目录的 `index.html`，需保留仓库相对目录。

背景实际使用 `crates/app/assets/wallpapers/norma-awake.mp4`。视频在页面底层持续播放，切换任务和进入画布不重新挂载视频。减少动态效果时默认暂停，可主动播放。

## 页面与交互

- **项目频道**：桌面工作台、官网与品牌分别保存频道讨论。频道负责目标与跨任务安排；每项工作有常驻的独立线程入口。
- **任务线程**：每项工作独立保存输入草稿、阅读位置与消息；任务切换不会把别的任务对话混进来。输入框明确写出当前对象。
- **任务进度**：右侧随当前线程切换，显示阶段、已完成步骤、执行者、最近有效进展、待决定事项及推荐依据。没有猜测完成百分比。
- **工作总览**：按项目与阶段筛选所有工作。统计随项目范围同步变化；每条记录可回到对应讨论或定位画布卡片。
- **需要你处理**：跨任务集中查看回答、授权、验收。采用后状态写回原工作；答复只恢复执行，验收仍显示待合并。
- **原画布入口**：频道导航只存在于 Norma 页面。进入示例画布后导航消失，目标卡片居中；返回恢复原线程和草稿。
- **明确接管**：接管后暂停对该 Agent 的自动采用，交还后才恢复。
- **新工作**：选择项目、记录目标与边界后创建独立讨论，初始显示待安排，不声称已经执行。
- **查找与组织**：搜索标题、项目和 Agent；折叠项目任务；未读与草稿标记区分显示。
- **窄窗口**：进度面板按需展开 / 关闭；手机宽度的导航改为显式展开，不压缩对话内容。

所有数据和回执均为本地交互示例；刷新页面恢复初始数据。新建工作不调用真实 Agent，也不执行部署、合并或 PTY 操作。

## 设计依据

参考 `apple-design`、`frontend-design`、`emil-design-eng`、`ponytail`，承接既有 Super-Agent 调研：

- 项目、工作、执行者分开表达。用户按事情沟通，Agent 名只作为负责人和证据来源。
- 每项工作有稳定可进入的讨论入口，避免依靠全局输入框中的隐含上下文。
- 正常进度按需查看；必须由人参与的事项集中处理。
- 采用 Slack 的频道与线程组织方式，保留 Norma 的视频、材质和画布入口。
- 按 Apple 原则提供明确位置、状态反馈、键盘操作和返回路径。常用切换即时完成；没有新增循环 UI 动画。
- 鼠标 hover、pressed、键盘 focus、选中与禁用状态均可见；对话框支持 Escape、Tab 焦点约束，Enter 发送、Shift+Enter 换行，IME 组合期间不误提交。
- 生产集成时，仍需将视图状态与工作归属落到 runtime，并优先使用 `ui::component`；视频维持现有低拷贝路径。浏览器模拟不等于正式 App 集成。

## 验证

2026-11-04：6 组独立 Chrome / Playwright 测试通过。

| 场景 | 验证要点 |
| --- | --- |
| 并行任务隔离 | 两份草稿分别恢复，消息只出现在所属线程，右侧进度同步切换 |
| 总览与待办跳转 | 回到正确工作，采用后计数和阶段同步，未验收任务保持待验收 |
| 画布与接管 | 目标卡片横纵居中误差 < 4px，画布无频道栏，接管和交还后禁用态正确 |
| 频道与新工作 | 新任务进入对应项目，频道草稿独立，搜索打开正确线程 |
| 阅读、验收、视频、语言 | 阅读位置恢复误差 ≤ 2px；验收后待合并；视频真实解码 1920px 且可暂停；英文入口正确 |
| 项目统计与窄窗口 | 官网初始统计 0/0/0/1；待办归零；900px 可打开并关闭进度 |

另外检查了中英文主要页面、1440 / 1280 / 1024 / 900 / 768 / 390px 布局，无横向溢出和脚本异常。`python3 scripts/check-i18n.py` 已通过。未修改 Rust，不运行无关 cargo 构建或正式 App desktop-e2e。
