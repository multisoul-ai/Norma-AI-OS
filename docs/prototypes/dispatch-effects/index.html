接入 Norma 的方式
  • 新增 DispatchEffectStyle 设置项（Settings → 外观 → 派发特效），设置页复用这里的即时预览。
  • 飞行与命中时长改由 style 提供，替换 motion/dispatch_receipt.rs 里固定的 IDEA_FLIGHT_DURATION；build_paint_plan 按 style 分发到各自的 paint_*。
  • 所有款式都只用 PathBuilder 描边/填充和 PaintQuad，与现有流星同一套 GPUI 原语，不需要模糊或着色器。
  • 减少动态效果时统一回落为卡片描边脉冲；Agent 间交接仍可单独保留离子画法。
