# Norma 大脑与语音汇报原型

入口：[index.html](index.html)。单文件，无需构建，直接用浏览器打开。设计文档见 [`docs/design-docs/2026-10-23-norma-brain-acp.md`](../../design-docs/2026-10-23-norma-brain-acp.md)。

页面有四个标签：

- **原型**：模拟桌面工作台，左侧是运行概览，中间是 Agent 卡片，底部是播报条。打开右上角的“语音汇报”，再点“演示一段”，依次演示三件事：
  - Codex 完成后，大脑派 Cursor 接着做下一步；
  - Claude Code 申请 `cargo test`，大脑约 20 秒后放行，判断期间可以点“我来处理”接管；
  - 另一张 Claude Code 卡申请 `git push`，命中高风险规则，直接问你；没有回应就进入“需要你处理”。

  “模拟你插话”演示播报让路：前台先回答，派活转给后台。“语音模式”按钮可以切换前台由谁回答。
- **架构**：感知、决策（前台对话加后台 ACP 大脑）、执行、表达四层。
- **大脑设置**：选择后端、策略和模型，设置自主权限和高风险清单。
- **决策与待定**：已确认的决策、风险和待完成事项。

所有数据和回执都是本地示例，没有连接真实会话。演示时间是真实时间的 1/4。

原型是设计稿。实际实现与差异见 [设计文档](../../design-docs/2026-10-23-norma-brain-acp.md) 的 G 节：设置页只有开关、后端、策略和适配器安装，没有模型下拉与自主权限开关；审批代理只覆盖带手机控制的卡片。
