# Norma 助手模式交互原型

入口：[index.html](index.html)。无需构建；默认背景使用项目资源的本地副本，声音分析使用附带的 macOS 语音服务。

**当前版本是左侧对话抽屉、中间 Live Node 画布、右侧多标签内容抽屉。** 两侧可独立收起，半透明材质透出贯穿整个窗口的项目默认 Earth Horizon 背景。左侧抽屉顶部可在「对话 / 运行概览」间切换；画布右上角逐个显示智能体状态与步骤（如 Bella 4/6、Bruno 待开始）和待处理角标，点它即切到左侧概览，也可把概览弹出为画布上的悬浮面板。顶部抽屉按钮采用统一的面板图标。中间只有智能体和终端示例卡片。画布下方的页面切换 Dock 只展示布局。球体、抽屉、内容切换及视频动效保留。页面为静态示例，尚未连接真实会话。下文的早期全屏模式说明属于历史记录。

直接双击 HTML 可查看视觉与文字交互；声音驱动体验需在 macOS 上通过以下本地服务打开，服务使用系统自带的 `say`（Tingting 声音）和 `afconvert`，浏览器通过 Web Audio 播放及分析实际 PCM。浏览器支持 `SpeechRecognition` 时可使用其识别能力；文字指令不需要麦克风权限。

```bash
python3 docs/prototypes/norma-assistant/server.py --port 8765
```

打开 `http://127.0.0.1:8765`。画布初始展示两张智能体和两张终端示例卡片；点击“演示一下”，或在左侧输入：

- “看看项目进度和网页”：在右侧打开两个标签。
- “找一下设计文件”：在右侧打开内置示例文件。
- “看看图片和视频”：在右侧查看图片与可播放的动态预览。
- “关闭网页”：关闭对应标签，保留其他内容。
- “收起所有卡片”：收起右侧示例内容，画布节点仍可见。

体验声音响应：点击左栏顶部扬声器开启播报，再输入“看看项目进度”等文字指令。点击同一扬声器关闭时立即停止播放。普通静态 HTTP 服务不提供 `/api/tts`，无法体验此声音分析。

“打开网页”会在右侧抽屉新建网页标签。文件、图片、视频和进度也使用同一个多标签阅读区；中间 Live Node 卡片持续可见。底部页面 Dock 只展示布局；运行概览的归属与状态为示例内容，定位和预览按钮可以操作。

左右抽屉可分别收起，中间画布会相应扩展；窄窗口一次只展示一侧。左侧球体、聊天记录与输入框保留，右侧标签可独立滚动与关闭。Esc 优先收起已展开的悬浮概览，随后可关闭右侧浏览器或打断尚未完成的回应。输入框下方提示、左侧底部状态栏和画布顶栏的示例说明已移除。本轮不保存示例状态。

## 对齐产品：对话入口隐藏、想法栏三段切换 · 2026-10-22

- **左栏固定为运行概览**：与产品一致，「对话 / 运行概览」切换和悬浮钉已隐藏（`LEFT_CHAT_ENTRY_VISIBLE=false`），旧的持久化视图与悬浮状态不再恢复；对话相关逻辑保留以便恢复入口。右上角状态按钮只负责展开左栏并聚焦首行。
- **想法栏分段**：顶部 `待办 n │ 已指派 n │ 已完成 n`（Material segmented button，胶囊轮廓，选中段 tonal 填充，←/→ 切换）。一次只显示一类；已指派、已完成顶部有“说明 + 清空”行，清空可撤销；每段有各自空状态。取代原来的“已指派”折叠小节。
- **输入框**：胶囊形，聚焦时才显示“回车添加 · ⇧回车换行 · 可粘贴图片和链接”提示行。
- **已完成**：想法的执行者状态为 `done` 时进入此段（原型暂无自动完成路径，仅展示空状态）。

## 运行概览改为工作空间级智能体管理 · 2026-10-22

运行概览不再按“当前项目 / 其他项目”分组，改为面向整个工作空间、按状态跨项目分组，回答三个问题：谁在运行、谁待开始、什么需要我处理。栏目顺序：需要你处理 → 运行中 → 待开始 → 想法。

- 顶部状态概览：三枚 Material tonal 卡片（待你处理 / 运行中 / 待开始）显示数量，点击展开并跳到对应分组，分组标题短暂高亮（减少动态效果时不动画）。
- 智能体行：状态与步骤条不变，第二行用项目标签标明归属（如 `Norma-AI-OS`、`设计草稿`）；未加载项目的智能体（Cora）并入同一状态分组，标明“上次状态 · 未加载”，点击为切换项目示意。
- 状态联动：想法派给 Bruno 后，其行从“待开始”移到“运行中”，分组计数与顶部概览同步刷新（`refreshRunCounts`）。
- 右上角状态条同为跨项目汇总：`◔ 2 运行中 · ○ 1 待开始 │ ③ 待处理`，不再逐个列出智能体；顶栏变窄时只留圆环与数字，文字进读屏标签。画布卡片标题仍显示各自状态。
- 设计依据：Material 3 的 tonal 状态卡、48px 行、状态层与单一动作；位置与反馈仍遵循 Apple HIG。

## 运行概览：位置与交互

**位置：左侧抽屉的「运行概览」视图，与「对话」并列；画布右上角保留状态显示。** 概览是要停下来读的内容，放在左栏能占满一栏高度，也不遮挡画布；右上角状态只负责“一眼看到”和“一键切过去”。需要边聊边盯时，可以把概览弹出为画布上的悬浮面板。

```text
┌ [◧] norma  ▷ 🔈 ? ┬ Norma OS / Norma-AI-OS   [◔ Bella 4/6 • ○ Bruno 待开始 │ ③ 待处理] [内容浏览器] ┐
│ [ 对话 │ 运行概览 ③ ] │                                                                          │
│ 运行概览        📌  │   Live Node 画布                                                         │
│ 需要你处理        3  │   （卡片标题同步：运行中 4/6 / 待开始）                                    │
│ ● 待审核 · 抽屉…  定位│                                                                          │
│ ● 成果待查看 …   打开│                                                                          │
│ 当前项目 · Norma-AI-OS│                                                                          │
│ ● Bella 运行中 1 待审核│                                                                         │
│   ▬▬▬▬▬▬▬▬▬▬▬▬░░    │                                                                          │
│   第 5/6 项 · 原型交互验收 · 18 分                                                                │
│ 其他项目   上次状态   │                                                                          │
│ [ 说说你的想法…   🎤 ]│  ← 输入区两种视图共用                                                     │
```

| 方面 | 规则 |
| --- | --- |
| 一眼可读 | 右上角状态逐个显示「进度环＋名字＋已完成数 n/m」，在等你处理时环上带琥珀点，待开始为空心灰环，末尾是待处理角标。顶栏变窄时只留进度环、步数和角标，名字移到读屏文字。画布卡片标题同步「运行中 4/6」「待开始」。进度取自智能体自己的待办清单（最近一次完整列表），概览行写「第 n+1/m 项 · 进行中项」；没有待办清单时不画进度条、不估算。生产实现在智能体较多时按“在等你 > 运行中 > 出错 > 待开始”最多显示 3 个，其余折为 +N。 |
| 抽屉切换 | 抽屉顶部 `对话 │ 运行概览 ③` 分段切换（tablist）：点击或 ←/→ 切换。概览视图隐藏球体、标题和聊天记录，保留输入区，可以边看状态边问 Norma。Esc 从概览回到对话。 |
| 右上角切换动作 | 点状态按钮：抽屉收起时先展开再切到概览；已在概览时切回对话（按钮 `aria-expanded` 同步）。概览已悬浮时，点状态按钮聚焦悬浮面板。键盘触发会把焦点放到第一行。 |
| 切换动效 | 进入概览从右侧 10px 滑入并淡入，回到对话从左侧滑入，200ms，方向对应 tab 顺序；减少动态效果时只淡入 120ms。行切换、预亮等高频操作没有动画。 |
| 排序与行 | 需要你处理（审核 > 成果 > 文件）→ 当前项目智能体 → 其他项目（只显示上次状态，标明“未加载”）。每行一个动作：定位画布卡片 / 在右栏打开 / 切换项目（示意）。智能体行另有分段步骤条与「第 n+1/m 项 · 进行中项 · 已运行时长」。悬停或聚焦行时预亮对应画布卡片。抽屉里的概览执行动作后不收起。 |
| 悬浮固定 | 概览标题栏的图钉把概览弹出到画布右上方的悬浮面板，抽屉回到对话，「运行概览」tab 与右上角状态显示图钉。拖动标题栏或 ⠿ 手柄移动（1:1 跟手，限制在画布内），手柄可用方向键移动（Shift 加大步长），双击标题栏复位。再点图钉或点「运行概览」tab 收回抽屉。视图、悬浮状态与位置只保存在本机浏览器，存储不可用时照常工作。 |
| 可读性 | 最小字号 11px，状态同时用文字和颜色表达；减少透明度时悬浮面板使用实色。 |

设计依据：分段切换与列表行参考 `docs/design-docs/material-menus.md`（48px 行、单一动作、状态层、键盘浏览）；位置、直接操作、即时反馈与减少动态效果遵循 `apple-design`。生产实现用 `ui::component` 的 Tab/List，数据来自 G0 契约中的任务、审批与产物引用；切换左栏视图应注册为可在 Settings 中修改的快捷键。

验证：`node --test docs/prototypes/norma-assistant/tests/*.test.mjs` 中的 canvas 测试覆盖位置、切换、排序、直达目标、一眼可读状态与悬浮固定。

## 想法清单：先记下，再派给智能体 · 2026-10-20

**位置（2026-10-21 调整）：不再单独占一个标签，而是并入「运行概览」，作为其中一栏。** 左抽屉只有「对话 / 运行概览」两个标签；概览里的栏目顺序固定为：需要你处理 → 当前项目 → 想法 → 其他项目。想法是尚未派发的意图，运行概览是已经在跑的事，放在一起便于从“想法”直接拖到上方“当前项目”对应的卡片；想法的待办数显示在该栏标题上，运行概览标签的琥珀角标仍只表示在等你处理。

**分栏规则：** 每一栏有固定高度（各栏有基准高度 190 / 210 / 236 / 88px，抽屉放不下时按比例收缩，有多余高度时按 1 : 1.2 : 1.4 : 0.6 分摊；各栏标题始终可见），内容超出时只在栏内滚动，不挤压其他栏；抽屉整体过矮时才出现外层滚动。栏标题是折叠按钮（▾/▸），折叠后其余栏分走空出的高度，折叠状态记在本机。想法栏底部固定一个“添加想法，回车保存”的输入行（手动添加，来源记为“手动添加”）；「已指派」子分组可折叠，并有「清空」按钮（清掉已派出的记录，6 秒内可撤销）。

| 环节 | 规则 |
| --- | --- |
| 记下 | 对 Norma 说或输入“记一下：…”“别忘了…”“…记下来”，她回复已记下，「想法」角标跳动并加一；也可在想法栏底部的输入行手动添加。首次打开预置 3 条示例想法。 |
| 清单 | 「待办」按记录顺序列出，行内是标题与“多久前 · 来自对话”；悬停或聚焦才显示「指派 ▾」与删除。已派出的想法进入「已指派」分组，写明交给谁与状态（运行中 / 已排队），点击或回车定位到卡片，可折叠、可一键清空。 |
| 拖拽指派 | 按住想法行拖动（触屏需抓左侧手柄），预览条 1:1 跟手；拖动期间画布上的智能体卡片出现虚线框与“交给 xxx”，终端卡片变淡，底部浮出「＋ 新建智能体来完成」。悬停目标立即实线高亮；松手投递，落空、Esc 或指针取消则预览条弹回原位，想法不变。 |
| 流星 | 松手后预览条收成光点，沿一条弧线飞向目标卡片的正中央，带渐隐尾迹与火花；落点处才真正写入：卡片边框脉冲、终端新增行高亮、顶栏与运行概览中的 Bruno 同步为“运行中”。时长约 0.7–0.9 秒，距离越远略长。 |
| 投递语义 | 空闲智能体（Bruno）：任务成为它的当前任务，状态变“运行中”。忙碌智能体（Bella）：追加“已排队”两行，状态角标变“运行中 4/6 · +1 排队”，当前任务完成后自动开始。拖到「新建智能体」：流星飞向即将出现的位置，落点处新卡片（Cleo、Dana…）才入场，并自带这条想法。 |
| 等价路径 | 键盘：想法行上方向键移动，回车打开指派菜单（↑↓ 选择、回车确认、Esc 返回行），Delete 删除；删除有 6 秒“撤销”。对话：“把第二条想法交给 Bruno”“让新智能体做刚才那个想法”“看看想法清单”。菜单与对话触发的流星从行的手柄或输入框出发。 |
| 减少动态效果 | 不画流星、不做预览条弹回动画，直接落地；落点用无位移的边框闪烁替代；投放区只淡入淡出。 |
| 状态 | 想法与新建的智能体卡片只保存在本机浏览器（存储不可用时照常工作）；不会连接真实 Agent Runtime，卡片内容为示例输出。 |

设计依据（`apple-design`）：松手前后全程直接操作（1:1 跟手、保持抓取偏移、可随时 Esc 中止并原路弹回）；响应优先（按下即有按压态，拖动即现目标）；动效服务空间连续性——流星把“从清单到卡片”的归属关系画出来，每次指派一次、约 0.8 秒，不做常驻装饰。列表与菜单遵循 `material-menus.md`（48px 级行高、单一主动作、状态层、键盘浏览）。生产实现建议：想法清单作为 Storage 中的工作空间实体，指派调用现有 Agent 任务投递接口；流星为 `app` 层纯视觉叠加，不阻塞任务投递。

验证：`node --test docs/prototypes/norma-assistant/tests/*.test.mjs`（`ideas.test.mjs` 覆盖记下/口述指派解析、状态流转、存储容错与接入点）；真实浏览器中已验证对话记下、拖到 Bruno、拖到新建、菜单指派与流星落点。

## 范围

这是对话驱动界面的视觉与交互验证，没有接入 Norma 的 Agent Runtime、生产 ASR/TTS 或项目数据。语音播报由本地 macOS 系统声音合成，音频不发送到远程 TTS。进度、网页和文件正文为预置示例；全屏网页呈现完整可滚动的本地网页布局，并非 Apple 官网实时内容，顶部提供原网页入口。图片是原创 SVG；视频卡片为 Canvas 动态预览，并非真实视频播放器。浏览器语音识别可能使用其在线识别服务。

## 设计依据

参考 `.agents/skills/apple-design`、`.agents/skills/animate`、`.agents/skills/emil-design-eng`、`.agents/skills/review-animations` 及已安装的 `frontend-design`。

- 内容优先：中间画布只承载智能体和终端节点；左侧抽屉可切到运行概览、右上角常显智能体状态，右侧按需阅读具体内容。
- 材质与层级：项目默认 Earth Horizon 背景贯穿窗口，两侧抽屉、运行概览悬浮面板与底部 Dock 使用半透明材质；正文使用 macOS 系统字体。
- 即时反馈：按下立即反馈；倾听、思考、回应均有可读状态；语音权限或服务问题在页面说明。
- 空间连续性：抽屉沿各自边缘收放；右侧标签切换沿用已有动效，中央 Live Node 不被内容覆盖。
- 可访问性：所有按钮有标签与可见焦点，输入可用键盘，dialog 支持 Esc 和焦点恢复；减少动效时圆球静止、卡片仅淡入，减少透明度及增强对比度也有替代样式。
- 科幻感用于助手的存在感；背景静止，运行概览只呈现 Agent、任务与待办信息。

未来 GPUI 实现需验证钉死版本，材质映射到共享主题，卡片对应真实 Live Node，圆球采用 Metal 绘制，对话决策放到域层；本轮没有改动生产 Rust 代码。

## 历史方案记录

以下小节记录早期双栏与全屏方案，不代表当前三栏抽屉原型。

### 左侧对话与右侧画布 · 2026-10-17

参考 `.agents/skills/apple-design` 的熟悉性、内容优先、即时反馈及减少动态效果原则，参考 `.agents/skills/emil-design-eng` 与 `.agents/skills/review-animations` 检查动效目的、可中断性和性能。左栏采用持续可见的助手与输入区，只让对话记录滚动；右栏保持完整画布宽度，卡片可在其中展开为完整内容。没有为高频输入新增动画，沿用已有球体、卡片和内容过渡。网页、文件和视频内容在右侧切换，不覆盖左侧对话；减少动态效果时继续采用既有淡入替代位移。

| Before | After | Why |
| --- | --- | --- |
| 中央球体与两侧信息卡片 | 左侧固定对话，右侧双列画布卡片 | 对话入口与内容展示各有稳定位置 |
| 完整内容覆盖整个页面 | 完整内容仅覆盖右侧画布 | 阅读时仍可查看历史并输入新消息 |

## 连续动效优化 · 2026-10-03

当前版本以这里的参数为准。目的为保持空间连续性、反馈助手状态、衔接内容切换。按 apple-design 的移动弹簧采用 response=0.4 s、damping=1：X、Y 和缩放分别保存位置与速度，通过临界阻尼解析解推进。圆球在约 0.4 s 内走完 98% 的路程，之后收敛；这段跨越主视图的助手迁移保留物理减速尾段，没有终点弹跳。普通控件与内容淡入仍控制在 280 ms 内。

| Before | After | Why |
| --- | --- | --- |
| 圆球 260 ms ease-out，取消后重启速度 | 临界阻尼移动，反向继承当下位置和速度 | 避免快速切换时硬切方向，保持助手的位置连续 |
| 提前将圆球缓冲区缩到 100 px 再放大移动 | 飞行保留较大端分辨率，停靠后再降采样 | 大小变化保持清晰，不每帧重建绘制缓冲区 |
| 输入框和文案瞬间换位，内容退出立即消失 | 输入框同步移动，文案交接淡入，正文进入与退出均过渡 | 避免多个层分别跳变；新操作可以随时接管 |
| 全屏内容之间直接替换 DOM | 旧内容快照 160 ms 淡出，新内容 240 ms 淡入 | 网页、文件、图片和视频切换保持视觉连续；快照不可交互并自动清理 |
| 圆球约 30 Hz 节流、能量按帧变化 | 光流与位移共用 requestAnimationFrame，能量按时间平滑 | 刷新率不改变响应节奏；低频呼吸、单条轨道光、状态波形提供克制的科技感 |
| 卡片关闭立刻删除，多卡片同时出现 | 收起 160/200 ms 淡出，出现间隔 60 ms，淡出中召回复用卡片 | 让信息出现与离开的节奏一致，避免重复节点 |

审查结论：**Approve**。位移仅写 transform；场景衔接使用 transform/opacity；布局仅在目标切换时测量。后台跳过圆球绘制。键盘触发视图切换即时完成；减少动效时不播放位移，圆球固定着色器时间，状态反馈与文字继续保留。没有增加第三方依赖。

## 语音播报波动 · 2026-10-04（历史版本）

本节记录此前使用浏览器 speechSynthesis 的版本；其程序节奏与扩散涟漪已被下一节的真实声音分析替换。

## 真实声音驱动 · 2026-10-04

此前浏览器 `speechSynthesis` 不提供 PCM，轮廓使用固定节奏，无法对应每句话的音量和音高变化。当前播放链路为：本地 `say` 合成 → 24 kHz 单声道 PCM WAV → Web Audio `BufferSource` → `AnalyserNode` → 扬声器。用于分析和听到的声音来自同一路音频。

`server.py` 仅监听 `127.0.0.1`，负责静态页面与 `/api/tts`。文本作为文件输入系统语音工具，临时文件自动清理；合成结果缓存 32 条，并行合成上限为 2。声音启动最多等待 20 秒；播放长度由音源结束事件决定，打断会取消请求及正在播放的音源，迟到结果不会重新开始播报。

### 声学映射与连续性

| 声音特征 | 控制方式 |
| --- | --- |
| PCM RMS 音量 | 决定主要波动幅度；约 -48 dBFS 以下按静音处理 |
| 70–650 Hz 基频 | YIN 估计实际音高；在有限范围内调整幅度、缓慢的轮廓流动速度 |
| 70–350 Hz 低频能量 | 增加宽阔、柔和的整体形变 |
| 1800–6000 Hz 高频能量 | 增加小幅边缘细节；无周期噪声仍有能量，但不伪造音高 |
| 频谱重心 | 平滑调整光场内部运动速度 |

声学窗口约 85 ms，分析以 30 Hz 更新，每个显示帧再做包络平滑。起伏上升响应为 75 ms，回落为 105 ms；音高和频段以 120 ms 平滑。运动相位积分使用已平滑的音高和重心，避免参数改变时突然跳到另一方向；单帧推进上限为 50 ms，后台恢复不补播。

移除固定播报节拍、两层扩散光圈与高阶快速抖动，轮廓只保留小幅 2/3 阶起伏。播放中的静音停顿让声音幅度自然回落。极光、星云、波纹共用同一声音分析；全屏时仅左下角光场变化，正文宽度和助手位置保持稳定。遵循 apple-design 的连续反馈、内容优先与克制原则：减少动效关闭轮廓运动、保留静态强度和状态文字；WebGL 不可用时采用小幅局部缩放。

### 验证与证据


## 卡片连续过渡 · 2026-10-04

参考当前 `crates/app/src/workspace/desktop/camera.rs` 的多工作空间相机：k=225=15²、c=30=2×15，使用同样的临界阻尼，位移和缩放保留中途反向的速度。没有修改生产 Rust。

- 卡片从 92% 尺寸、向助手方向 6 px 的轻微偏移和 12 px 的纵向偏移连续展开；透明度采用独立的快速包络，同一批卡片错开 50 ms。
- 收起沿原路径反向退场；退场时离开布局流，剩余卡片从实际可见位置平滑补位。外壳负责布局、内层负责进入，避免两个 transform 相互覆盖。
- 退场中召回复用同一个元素并保留运动状态。退出时控件立即 inert / aria-hidden，焦点返回输入；实际元素在退场收口后删除。
- 普通文字对话提交与鼠标调出都展示该过渡；减少动效时只做 120 ms 淡入淡出。全屏阅读、内容滚动和助手外观保持可用。
- 复用现有 RAF 和解析弹簧；每帧只更新 transform / opacity，不在循环内测量布局；结束清理 will-change 和退出元素。

验收先增加 4 项聚焦测试，确认缺少卡片运动接口时失败，再实现。全部 43 项 Node 测试和 6 个内嵌脚本语法检查通过。

真实 Codex 浏览器通过 Computer Use 验证：入场过程中实际缩放约 0.954、透明度约 0.826；文字对话同批卡片透明度依次约 0.741 / 0.352 / 0 / 0，确认不是同时突然出现。收起进度后，文件卡片最终平滑归位到 y=215 px，进度节点被删除。800 px 窗口下为两列 333 px 网格，无横向溢出；已恢复默认 1060 px 窗口。展开网页并返回后保留四张原卡片，无重复 id、无残留退出元素，控制台无 error/warn。截图为 `assets/assistant-card-transition.jpg`。

Apple 设计原则落地：运动用于连接状态与空间位置，镜头式缩放无终点弹跳；内容稳定后静止，减少动效保留可见反馈。
