Lead: 左侧与 Norma 对话，中间始终操作当前工作空间的真实画布。右侧按需展开内容区，用多个标签查看网页、文件、图片与视频。

## A 三栏如何协作 {span=2}

```tree
工作空间目录 | 满窗选择工作空间
  当前桌面工作空间 | 进入后显示三栏工作台
    左侧 Norma 对话 | 查询、明确目标、派工与逐目标回执
    中间真实画布 | 原有 Dock、项目区域与同一批 Live Node
      项目总览 | 同时操作多个项目的真实卡片
      项目聚焦 | 放大同一项目画布，不复制会话
    右侧内容区 | 按需展开，可收起与调整宽度
      多个标签 | Browser、文件、图片、视频各自保留位置
```

```callout info 同一份内容
右侧标签引用来源卡片或文件，不创建第二个 Agent 会话。关闭标签只关闭该次展示，不停止中间画布上的任务。
```

## B 三栏的关键边界 {span=2}

| 区域 | 负责什么 | 保留什么 |
| --- | --- | --- |
| 左侧对话 | 回答当前工作空间的问题，向明确目标派工 | 对话历史、目标与每个目标的回执 |
| 中间画布 | 展示并操作真实项目、Agent、Terminal 与 Dock | 卡片身份、布局、镜头、输入焦点与运行实例 |
| 右侧内容区 | 并排阅读来自不同卡片的网页与产物 | 各标签的滚动、播放位置和来源标记 |

右侧收起后，中间画布获得更多空间。窗口过窄时优先保证卡片可读，右侧内容区改为临时展开。

## C 多标签如何使用

| 操作 | 中间画布 | 右侧内容区 |
| --- | --- | --- |
| 从 A 卡片打开设计文件 | A 卡片继续显示执行状态 | 新增文件标签，标出 A 与所属项目 |
| 再打开 B 提供的网页 | B 卡片保持原会话 | 新增 Browser 标签，文件标签仍在 |
| 切回设计文件 | 两张卡片都继续运行 | 恢复该文件的阅读位置 |
| 关闭文件标签 | 来源卡片和任务不受影响 | 仅移除文件标签 |

同一资源重复打开时定位已有标签。切换工作空间后，各空间的标签列表分别保留；来源失效时显示原因。

## D 输入与身份边界

```kv
左侧 Norma: 当前桌面工作空间级查询与跨项目派工
中间 Agent 卡片: 仅向该卡片的现有会话输入
右侧 Browser: 在原 Browser 会话中导航与阅读
右侧文件标签: 引用项目、文件版本与来源任务
稳定身份: desktop_workspace_id + area_id + node_id
任务回执: 每个目标使用独立 task_ref
```

模糊目标先澄清。点击左侧回答定位中间的原卡片，再按需打开右侧标签。

## E 进度与产物如何可信 {span=2}

```flow LR
[(真实 Live Node 与项目区域)] -> [状态索引]: 卡片和归属
[(Hook、RuntimeEvent 与任务日志)] -> [状态索引]: 阶段和回执
[(文件引用与 Preview Card)] -> [状态索引]: 路径、版本和来源
[状态索引] -> [左侧 Norma]: 带来源的短回答
[状态索引] -> [中间真实画布]: 定位、徽章和运行状态
[状态索引] -> [右侧多标签内容区]: 打开同一来源
```

```callout warn 只显示可观察的进展
有明确步骤与验收记录时才显示百分比。真人进展需要分配、提交或主动更新；在线状态不等于正在执行。
```

## F 当前方案需要修正的地方

| 当前风险 | 调整 |
| --- | --- |
| 单个预览替换整个画布 | 中间画布持续可见，右侧负责内容阅读 |
| 打开第二份内容会覆盖第一份 | 右侧使用多个标签，各自保存阅读状态 |
| 固定侧栏挤压终端 | 左右栏可收起，窄窗口优先画布 |
| 查询与派工混淆 | 状态查询只读，明确目标后逐项提交 |
| 将文件改动归给某个人 | 显示任务来源；无法归因时明确标记 |

## G 交付顺序与验收

```timeline
1 | 三栏外壳 | 中间复用真实画布，左右栏可收起
2 | 多标签阅读 | Browser 与 Preview Card 保留来源和阅读位置
3 | 只读联动 | 对话查询真实状态，定位中间卡片并打开右侧内容
4 | 安全派工 | 明确目标、逐目标回执与失败隔离
5 | 真人协作 | 增加成员分配和主动进展记录
```

1. 打开 A 文件和 B 网页后，两张原卡片持续运行，两个标签可切换。
2. 关闭一个标签不关闭来源卡片；切换工作空间不串标签和任务。
3. 派工前检查目标；单个失败不重发其他已成功目标。
4. 球体、卡片与镜头动效保留空间连续性；中途操作可接管，减少动态效果时保留清晰反馈。

现行桌面工作空间规格将统一输入入口标为待定。实施三栏前，应将左侧 Norma 定为工作空间级入口，并修订现有验收标准。
