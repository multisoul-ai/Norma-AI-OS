# Norma 实时对话画布 · 五种视觉概念

生成日期：2026-10-04。使用内置 `image_gen.imagegen`，五款各用独立提示词生成。完整提示词见 [prompts.json](prompts.json)。

本组探索画布组织与交互模型，展示进行中的语音操作。均为静态概念图。

| 编号 | 方向 | 交互侧重 | 图片 |
| --- | --- | --- | --- |

Apple 设计原则落地：内容优先、清晰层级、功能性玻璃层、大面积留白和少量语音状态反馈。AI 位于任务边缘或当前内容附近，画布组织方式包括自由布局、全屏聚焦、关系连接、连续共创和多空间缩放。

验收：逐张视觉检查内容组织差异、异构内容展示和语音指令的可见操作结果；PNG 头、尺寸及复制哈希已验证。概念图不代表实时功能已实现。本轮未修改现有 HTML 或动画。
