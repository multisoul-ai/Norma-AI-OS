## B 连接与持续双工

1. 点击“连接”，等待“通话中”。
2. 说“你好，请只回答苹果香蕉”。
3. 确认听到“苹果香蕉”，画布上不出现悬浮转写框。
4. 在 Norma 说话时继续提问。
5. 确认仍能收音并理解新的问题。
6. 点击“静音”，再点击“取消静音”。

通过标准：双方持续听说，Dock显示通话状态，悬浮转写框不再遮挡画布。静音期间不上传真实麦克风音频。

## C 播报与任务分开控制

| 操作 | 应观察到 |
| --- | --- |
| 点击“停止播报” | 当前声音停止，待播音频丢弃 |
| 说“停止播报”或“停一下” | 同样停止本地播报 |
| 点击“恢复播报” | 接收新声音，不补播旧队列 |
| 说“恢复播报” | 输出恢复，麦克风无需重新启动 |
| 任务已接收时停止播报 | 任务继续运行 |
| 明确要求取消指定任务 | 返回真实取消结果 |

停止播报只控制本地声音。已传给服务端的任务事实不能据此视为撤回。

## D 项目工具与更正

1. 说“创建一个浏览器”。
2. 核对画布只新增一张卡片。
3. 查询任务，核对真实 ID 和状态。
4. 给已启用 Agent 派一个只读任务。
5. 确认“已接收”未被说成“已完成”。
6. 等任务结束，核对真实终态通知。
7. 在规划时补充或更正请求范围。

通过标准：操作与原话授权一致。旧规划被更正后不能继续写入。已产生的真实副作用仍须如实核对。

## E 挂断、重连与核对

1. 挂断后检查声音和麦克风释放。
2. 重连，确认旧音频没有复活。
3. 打开“操作与任务核对”。
4. 点击“刷新核对”，查看原命令和回执。
5. 核对任务稳定引用与当前画布卡片。
6. 切换项目，确认不显示旧项目报告。

待核对操作不会自动重做。没有匹配回执时，卡片存在也不能证明原请求已执行。

未确认接收的任务终态会持久保留。重连后可以补交；服务端接收确认不等于完整播报。
