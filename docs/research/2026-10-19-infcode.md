# InfCode CLI 接入要点（2026-10-19）

版本：`2.7.31-dev-cda6bacb-38947`（本机 `infcode --version`）。

## 已验证

| 项 | 结论 |
| --- | --- |
| 命令 | `infcode`；可用 `INFCODE_BIN` 覆盖 |
| 续接 | `--session <id>`（`-s` 为同义短旗）；**无** `resume` 子命令 |
| 数据目录 | `~/.infcode/`（DB/settings）；XDG 下另有 `~/.config/infcode/` |
| Hooks | Claude 式 `~/.infcode/settings.json` 的 `hooks`；`run --dir` 时 SessionStart 会触发 command hook |
| 插件目录 | `~/.config/infcode/plugins/*.js` **不会**像 OpenCode 那样自动加载（对照探测未打印加载日志） |
| Skills | 文档/迁移指向 `.infcode/skills/`；全局编排 skill 使用 `~/.infcode/skills/norma-orchestration/SKILL.md` |

## Hooks 事件（settings.json 文档）

二进制内 hooks-runtime 文档列出（节选）：`UserPromptSubmit`、`PreToolUse`、`PostToolUse`、`PostToolUseFailure`、`Stop`、`SessionStart`、`SessionEnd`、`TurnStart`、`TurnEnd`、`PreLlmRequest`、`PermissionRequest`、`SubagentStart`、`SubagentStop`。

Norma 安装列表对齐其中与状态灯/会话相关的集合（含 PermissionRequest / Subagent* / Turn*），**不**安装 OpenCode 插件侧的 `StopFailure`。
