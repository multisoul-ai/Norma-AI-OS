# 在两种语音交互模式间共享语音回合运行时

单次语音指令与持续聆听保留为互斥的产品模式，但共享模型校验、麦克风 PCM、流式 ASR、partial 反馈、Agent/工具执行与 TTS 回复运行时。单次语音指令以 `⌘E` 的 Hold/Toggle 结束作为唯一 Final Transcript 的边界，不使用 VAD；在 Agent Thinking 或 TTS 回复时再次触发会取消当前回合并开始新录音。持续聆听以 VAD 切分多个回合并在回复后保持会话；它在 TTS 回复时再次触发仅打断回复并回到 Listening，在 Thinking 时再次触发则结束整个长会话。切换模式、识别模型或输入设备会取消所有活跃的语音、Agent 与 TTS 工作，且不自动重启。这样删除旧听写专属的录音、识别与执行链，同时保留两种模式清晰且不同的会话语义；已有 `dictation` 设置与触发偏好在升级时迁移为单次语音指令。
