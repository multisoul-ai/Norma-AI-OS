# Norma OS 品牌视觉规范

版本：V2  
状态：当前方向  
产品：面向 vibe coding 的 macOS AI 伙伴

## 1. 品牌定义

Norma OS 是陪你把想法做出来的 vibe coding 伙伴。

你负责想法、方向与最终判断；Norma 理解当前项目，协调多个 Coding Agent，把终端、执行过程和产物留在同一张无限画布上。它不替用户夺走控制权，而是在需要推进时主动协作、需要判断时把决定交还给用户，直到想法真正落地。

无限画布与 Live Node 是这种伙伴关系的产品形态：工作持续运行、过程始终可见、任一节点都能随时接管，而不是把一切藏进聊天记录。

### 核心定位

- **品类**：面向 vibe coding 的 macOS AI 伙伴。
- **对象**：用自然语言和 Coding Agent 构建软件、但仍希望掌握方向与结果的人。
- **价值**：把模糊想法持续推进为可运行成果，同时让过程可见、可操作、可理解。
- **差异**：Norma 不只是聊天助手或 Agent 启动器；她在项目上下文中协调工作，画布中的卡片连接真实进程而非静态截图。
- **人格**：Norma 有观点、有情绪、可信赖，主动但不越权，陪伴但不打扰。

### 品牌承诺

> You set the direction. Norma keeps it moving.

### 辅助表达

- A desktop that works.
- Your vibe coding companion on Mac.
- Everything lives on one canvas.
- Make space. Keep it running.
- You know what it’s doing.
- Intelligence with a point of view.

## 2. 设计哲学

V2 采用受 Apple 产品哲学启发的设计方法，但必须形成 Norma OS 自身的语言。

### 2.1 产品是主角

视觉首先解释产品如何工作，再展示品牌装饰。画布、卡片、状态和人与系统的互动必须真实、易懂、可被想象使用。

### 2.2 复杂能力，简单呈现

一个画面只讲一个核心信息。通过留白、层级、对齐和渐进披露降低理解成本，不把所有功能同时堆到一张图里。

### 2.3 材质表达可信度

使用真实、克制的材质建立高级感：缎面铝、磨砂玻璃、陶瓷白、石墨黑、柔和半透明层。材质服务于结构与触感，不作为无意义装饰。

### 2.4 人本而非冷感

Norma 的角色、自然光、手势、语音和微妙情绪让系统具有陪伴感。技术应显得安静、自信、可亲近。

### 2.5 色彩是信息

大面积以暖白、石墨和银色为基础。高饱和色只用于身份、状态和关键动作，使色彩具有明确意义。

### 2.6 精度藏在细节里

统一圆角、阴影、边缘光、基线、间距与运动节奏。高级感来自一致的微小决定，而不是更多视觉元素。

## 3. 品牌人格

Norma OS 的气质关键词：

- Calm：冷静，不制造噪声。
- Intelligent：清晰表达系统正在做什么。
- Confident：不夸张、不讨好，有明确观点。
- Playful：在角色反应和状态色中保留趣味。
- Precise：对排版、材料、反馈与交互细节高度敏感。

品牌不是冷冰冰的极简主义，也不是过度可爱的二次元产品。目标是在“高端创意工具”与“有生命的 AI 伙伴”之间取得平衡。

## 4. Norma 角色系统

### 固定识别特征

- 年轻成年女性 AI 角色。
- 冷调浅紫色长马尾与整齐刘海。
- 大号白色 X 发夹。
- 黑色蝴蝶结。
- 深海军蓝剪裁服装，带低调蓝紫纹理。
- 蓝紫色眼睛。
- 默认表情冷静、自信、略带傲娇感。

### 表情状态

- **Thinking**：专注、轻微思考动作，不夸张焦虑。
- **Waiting**：平静等待，保留一点不耐烦的个性。
- **Complete / Done**：克制但真诚的满足感。
- **Error**：轻微懊恼或警觉，不使用崩溃式表情。

### 使用原则

- Norma 是产品体验的一部分，不是任意贴上的吉祥物。
- 产品信息密集时缩小角色存在感；情绪与陪伴叙事中才使用大幅人物。
- 不改变 X 发夹、发色、黑色蝴蝶结和核心服装识别。
- 不幼化角色，不使用儿童比例作为主要品牌形象；Q 版仅用于贴纸、摆件等衍生场景。

## 5. 标志与图标语言

### App Icon

图标由四个要素构成：

1. 圆角方形容器。
2. Norma 的黑色侧影。
3. 白色 X 核心符号。
4. 黄色、珊瑚、薄荷绿与蓝色的高饱和色域。

正式使用时应从产品源资产导出，不从品牌手册生成图中裁切。

### X 符号

X 是 Norma 的签名，也是系统状态的模块化符号。它可以用于发夹、状态标记、硬件细节、压印和动效中心，但不能被滥用为满版纹理。

### 安全区

图标四周至少保留一个 X 符号宽度的净空。不要在净空区域放置文字、边框或高对比元素。

## 6. 色彩系统

以下色值是 V2 方向的工作基准，生产前应结合实际 UI 资产复核：

| 名称 | 建议色值 | 主要用途 |
| --- | --- | --- |
| Warm White | `#F7F5F2` | 主背景、包装、明亮画布 |
| Graphite | `#111214` | 正文、深色界面、硬件材质 |
| Silver | `#D9DADD` | 铝合金、分隔、辅助背景 |
| Violet | `#6A5CFF` | Agent、工具调用、品牌强调 |
| Cobalt | `#2F80ED` | Thinking、链接、导航反馈 |
| Acid | `#D6FF3B` | Active、Waiting、关键动作 |
| Coral | `#FF6B7A` | Error、提醒、情绪强调 |
| Mint | `#64E0B5` | Complete、成功、可用状态 |

### 比例建议

- 70% 暖白或石墨基础色。
- 20% 银色、灰阶与半透明材质。
- 10% 或更少的高饱和状态色。

避免在同一画面中同时大面积使用全部强调色。

## 7. 字体与排版

### 字体气质

- 现代、人本、克制的无衬线字体。
- 标题使用较粗字重，依靠尺度与留白建立冲击力。
- UI 和说明文字使用清晰的常规字重。
- 技术状态、终端与测量信息可使用等宽字体。

### 推荐字体栈

设计稿优先：`SF Pro Display` / `SF Pro Text`（仅在许可和平台条件允许时）。  
跨平台替代：`Inter`, `Geist`, `IBM Plex Sans`。  
等宽字体：`SF Mono`, `Geist Mono`, `IBM Plex Mono`。

### 排版规则

- 标题短、直接、带观点。
- 一个跨页只保留一个主标题。
- 正文避免大段居中。
- 使用统一基线和大间距，不用装饰性分隔线填满空白。
- 品牌名固定写作 **Norma OS**。

## 8. 产品界面视觉

### 无限画布

- 使用暖白或极浅灰作为默认空间，降低长时间工作的视觉负担。
- 画布应显得无边界，但需要通过轻量导航和缩放反馈维持方向感。
- 卡片像桌面上的真实对象，具有轻微层次和可触感，但阴影必须克制。

### 卡片

核心卡片类型固定为：

- TERMINAL
- AGENT
- BROWSER
- PREVIEW

卡片标题、状态和内容层级必须一眼可读。避免把卡片设计成传统管理后台面板。

### 状态语言

| 状态 | 颜色 | 动态语义 |
| --- | --- | --- |
| Thinking | Cobalt | 平稳脉冲，表示持续推理 |
| Tool Call | Violet | 轨道或流动，表示执行外部动作 |
| Waiting | Acid | 呼吸节奏，表示等待用户或外部输入 |
| Complete | Mint | 短促绽放后归于稳定 |
| Error | Coral | 克制闪烁，明确但不惊吓 |

边缘光是信息反馈，不是氛围灯。无状态时应保持安静。

## 9. 摄影与材质

### 摄影原则

- 柔和自然光或大型柔光箱。
- 明亮无缝背景，或深黑高对比的状态场景。
- 使用真实透视、接触阴影和材料反射。
- 产品对象之间留出呼吸空间。
- 人手、姿态和环境只用于解释尺度与交互。

### 核心材质

- Satin Aluminum：结构、精度、耐用。
- Frosted Glass：层次、空间、轻盈。
- Ceramic White：亲和、清洁、安静。
- Soft-touch Graphite：专注、触感、专业。
- Clear Acrylic：Norma 衍生品与展示装置。

## 10. 动效、语音与声音

- 动效优先使用自然缓动，避免持续无意义运动。
- 状态变化应先传达含义，再表现个性。
- 语音波形细、稳定、低噪声，不使用夸张频谱墙。
- Norma 的语气冷静、自信、简短，偶尔带轻微傲娇感。
- 完成播报应让人感到任务被可靠接住，而不是制造打断。

## 11. 包装、零售与跨平台

- 包装以无涂布暖白纸、黑色文字和单个 App Icon 为主。
- 可使用压印 X、局部磨砂膜和少量透明材料。
- 零售空间使用大留白、独立产品台和可交互的发光卡片。
- 桌面端是完整生产力体验；移动端只展示状态、通知和轻量控制，不复制整张无限画布。
- 周边产品应优先选择与工作台有关的对象，如摆件、别针、贴纸、键帽和桌面配件。

## 12. 禁止事项

- 不使用 Apple 标志、Apple 字样或其他第三方品牌标识。
- 不一比一复刻 Apple 官网、发布会画面、包装结构或硬件产品。
- 不把所有品牌色同时大面积铺满画面。
- 不用过度辉光、廉价霓虹和通用科技渐变制造“未来感”。
- 不把 UI 做成拥挤的数据仪表盘。
- 不让 Norma 抢走核心产品信息，也不把她降格为无关贴纸。
- 不使用生成图中的伪文本、伪数据和伪规格作为正式产品信息。
- 不使用旧品牌名 **MultiSoul** 作为对外名称。
