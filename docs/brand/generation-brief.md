# Norma OS 生成式视觉简报

本文件用于后续生成品牌图、产品概念图、包装探索和编辑摄影。它描述方向，不替代最终设计与人工校对。

## 主提示词骨架

```text
Create a refined visual asset for “Norma OS”.

Product:
Norma OS is a spatial macOS workbench: an infinite canvas where live Terminal,
AI Agent, Browser and File Preview cards stay running.

Character invariants:
Preserve Norma as a young adult anime AI woman with a long cool-lilac ponytail,
straight bangs, a large white X hair clip, black ribbon, navy tailored clothing,
blue-violet eyes, and a calm, confident, mildly tsundere expression.

Art direction:
Apple-inspired design philosophy without copying a specific campaign or product:
radical simplicity, product as hero, human-centered clarity, precise optical spacing,
soft natural light, satin aluminum, edge-polished glass, ceramic white, graphite black,
subtle translucency, restrained motion, and emotional warmth.

Color behavior:
Use warm white, graphite and silver as the foundation. Use violet, cobalt,
acid yellow, coral and mint only as deliberate identity or status accents.

Typography:
Clean modern humanist neo-grotesk, short direct headlines, small precise mono notes,
generous whitespace and immaculate hierarchy.

Constraints:
Brand name must be spelled “Norma OS”. Never write “MultiSoul”.
Do not show an Apple logo, Apple wordmark, macOS logo, or unrelated brand marks.
Do not directly replicate a real Apple webpage, packaging system or hardware form.
No watermark, illegible paragraphs, visual clutter, generic tech gradients,
excessive glow, or crowded dashboard composition.
```

## 场景补充模块

### 产品界面

```text
Show a high-fidelity infinite canvas with four clearly labeled live cards:
TERMINAL, AGENT, BROWSER, PREVIEW. Use realistic content, restrained shadows,
subtle connection paths and clear state indicators. The canvas must feel spatial,
calm and usable, never like a generic admin dashboard.
```

### 角色摄影

```text
Use Norma as an intelligent companion inside the product story. Preserve every
identity invariant. Favor soft window light, composed posture and subtle emotion.
Avoid childish proportions, exaggerated expressions and decorative mascot placement.
```

### 状态与边缘光

```text
Treat light as information: cobalt Thinking pulse, violet Tool Call orbit,
acid-yellow Waiting breath, mint Complete bloom, coral Error flicker.
Use restrained luminance and premium optical detail. No ambient rainbow glow.
```

### 包装与零售

```text
Use uncoated warm-white paper, minimal black typography, one Norma OS icon,
embossed X details, frosted glass, clear acrylic and satin aluminum.
Keep objects widely spaced and photographed in soft architectural daylight.
```

## 生成后检查清单

- 品牌名是否准确写为 `Norma OS`？
- 是否完全移除了 `MultiSoul` 与第三方品牌标识？
- Norma 的发色、发型、X 发夹、蝴蝶结、服装和眼睛是否一致？
- 画面是否只表达一个主要信息？
- 是否有足够留白？
- 高饱和色是否承担状态或身份意义？
- 产品 UI 是否真实、清晰、不是通用仪表盘？
- 小字、色值、尺寸、终端内容和产品规格是否经过人工校对？
- 是否避免直接复刻 Apple 的具体物料？
