# 看图

按[执行规范](../../../../docs/quality/agent-execution-policy.md)确定范围后，从 `test/desktop-e2e/checks/<模块>/<场景>.checks.md` 选出覆盖本次差异的关键项。硬断言通过后，只打开这些项对应的截图；已复用的有效视觉证据引用原记录即可。

局部修复查看受影响状态及必要的前后对照；场景顺带产出的其他截图不自动纳入范围。完整场景验收才检查整份关键图清单。

对每一张给出一个结论：

- 符合：清单里“要看到”的内容都在图里，“不应看到”的内容都不在。
- 不符合：图和清单冲突，例如确认框还在、名称错了、按钮被挡住。
- 不确定：字糊、裁切或遮挡让你无法判断。写清缺的是哪一条，不要改判成符合。

用读图工具打开 PNG 的绝对路径。不要只根据 `report.json` 里的 OCR 文本下视觉结论。OCR 负责找坐标和脚本断言，看图负责遮挡、层级和按钮是否真的可辨。

连跑多次时，查看最后一次通过的本次范围内关键图；某一次失败则查看该次失败图和与失败行为相关的最近成功图。只对已检查或已复用证据覆盖的范围下结论。
