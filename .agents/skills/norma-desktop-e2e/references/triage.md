# 分诊

先看进程退出码，再看当次证据目录里的 `report.json`。不要把上一次运行的截图拿来解释这一次。

| 信号 | 结论 |
| --- | --- |
| 退出码 3，或报告 `kind` 为 `env` | ENV。锁屏、测试二进制缺失或不是 debug 构建、控制通道连不上、socket/端口冲突、无法把隔离窗口带到前台 |
| 退出码 1，或 `kind` 为 `product` | PRODUCT。画面文字、SQLite 或 `keep-me.txt` 与场景不符；隔离进程中途崩溃且日志没有地址占用 |
| 退出码 0 | 硬断言通过。视觉结论仍要单独看图，不能用退出码代替 |

PRODUCT 汇报要带上失败步骤名、`app.log` 末尾、失败截图路径，以及当时的 `workspaces` / `areas` 摘要。ENV 汇报停在环境原因，不把同一次失败再解释成产品缺陷。

连跑时一次 ENV 就停止后续次数。PRODUCT 失败记入通过率，不自动改场景去“跑通”。
