# 语音对话模式面板外框

运行 `bash scripts/desktop-e2e.sh settings-voice-mode-panel-size --visual`。

1440×870 窗口里，语音设置的三种对话模式必须共用同一外框。外框与其他设置页相同，约为 1008×609（视口七成），居中。切换时外框不跳动。外框由低彩度灰块占空比测量，看图只负责点进语音页和确认当前模式。

| 截图 | 要看到 | 不应看到 |
| --- | --- | --- |
| 01-legacy-panel.png | 语音指令选中；设置面板约占窗口七成，四周留出画布 | 面板铺满窗口、比其他设置页更大 |
| 02-doubao-panel.png | 豆包 2.0 语音选中；面板位置和大小与上一张相同 | 面板变小或位移 |
| 03-live-panel.png | GPT-Live 选中；面板位置和大小与前两张相同 | 面板变小或位移 |
