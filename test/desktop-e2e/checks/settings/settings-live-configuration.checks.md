# GPT-Live 设置真实窗口看图清单

Google Material 落地：连接为唯一主操作；偏好采用紧凑设置行、统一间距和语义色；低频诊断、已保存 Key 编辑渐进展示。系统字体、键盘和即时反馈遵循 Apple Design 平台习惯，不加装饰动效。

自动断言之外逐图核对，未看到的不计通过。测试 Key 为本地无效夹具，不作云端连接。麦克风状态只代表系统枚举，不等于真实采集或声学验收。
