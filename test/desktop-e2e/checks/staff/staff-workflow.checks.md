# 幕僚 M1 关键图

- 01-empty：三栏可读，任务列表/对话/原文件抽屉，不叠画布，语言正确。
- 02-proposal：用户原话、任务标题、状态分组、目标/理由/完整提议与采用按钮，无裁切。
- 03-hover：完整按钮命中与明确 hover，不改变布局。
- 03-pressed：按下比 hover 更明确，文字可读且尺寸不变；松开后才派发。
- 04-result：可信 Worker 结果归回原任务，自动待验收，已派发禁用。
- 05-artifact：原文件抽屉打开 Worker 真实产物，中左栏保留。
- 06-manual：完成重开后 Active，手动保护说明与回复。
- 07-fullscreen：原顶栏收起，退出入口、任务与文件保留；任务标题避开原生窗口按钮；Escape 恢复。
- 08-canvas：两张独立卡，未多派发，文件标签保留。
