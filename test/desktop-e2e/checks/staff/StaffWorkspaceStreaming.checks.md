# 工作空间与执行可见性

- 从所有项目总览点击幕僚，不能依赖已展开项目；顶部工作空间和项目筛选均可用。
- 按原型核对铺满顶栏以下的页面边界、中性灰阶、左栏密度、紧凑按钮与消息层级。
- 首分片前可见等待反馈；持有模型时可读部分正文和真实计划1/2。
- 后续分片追加，计划替换为2/2；模型结束后保存一条完整回复并停止等待。
- Alpha/Beta各自任务与草稿隔离；所有项目展示两个任务，TaskStore归属精确不同。
- Files跟随所选任务项目；抽屉从幕僚标题栏下方开始，外框中性灰黑，主窗口顶栏保持全宽。
- 请求失败保留既有回复、停止动画；切工作空间不能显示旧任务。
- 中英文分别执行，不把固定外部模型夹具当成真实服务验收。
