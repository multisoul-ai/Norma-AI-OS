# 幕僚任务列表密度

`staff-task-list-layout` 使用中文墨黑，`staff-task-list-layout-en` 使用英文蓝宝石之夜。

Material 的双行列表使用 64 px 行高、12 px 内边距和柔和选中底色。按 apple-design 的排版层级区分标题、辅助信息与时间。按 emil-design-eng 的高频操作原则即时反馈，归档图标显隐时保留相同位置。

| 截图 | 核对 |
| --- | --- |
| `01-selected.png` | 三条等待中的任务独立成行。长标题单行省略，头像、主次文字与时间不重叠。选中底色包住整行。 |
| `02-hover.png` | 悬停色和蓝色选中态可同时辨认。悬停时出现归档图标，时间与标题的位置稳定。 |
| `03-empty.png` | 零条目的筛选显示空态。 |
| `04-collapsed.png` | 窄窗默认折叠侧栏，可见任务列表开关。 |
| `05-expanded.png` | 窄窗展开后保持三条任务的间距，文字和操作都位于浮层内。 |
