# 输入框图片与用户消息边界

运行 `bash scripts/desktop-e2e.sh staff-composer-images --visual`；英文蓝宝石之夜运行 `staff-composer-images-en --visual`，中文使用墨黑。
若已有开发 App 占用默认 socket，给本次命令设置独立临时目录，例如 `test_tmp=$(mktemp -d /tmp/norma-img-e2e.XXXXXX)` 后运行 `TMPDIR="$test_tmp" bash scripts/desktop-e2e.sh staff-composer-images --visual`。这是测试环境隔离，不关闭用户 App。

遵循 apple-design 的内容清晰、分组和即时反馈：预览等比完整显示，与文字分行；用户气泡按内容撑高、图片宽度服从气泡内边距。保留既有加号资源、发送箭头、快捷键文案和移除交互，不调整其他卡片。

程序断言补充：第一次回车只发送一条包含原文和附件协议的消息；发送箭头再创建一条用户消息。单元测试覆盖四图、320/520/900/1400px宽度、长英文URL及短消息自然宽度。

加号按钮本次核对外观、无遮挡及布局测试中的按钮尺寸，图片添加走真实剪贴板；原生文件选择器未做选文件操作，不计作已验收。
