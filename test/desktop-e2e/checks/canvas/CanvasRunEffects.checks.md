参考：`docs/prototypes/agent-card-run-effects/index.html`、`review-animations`。六张卡片 Run 1–6 依次为 准备 / 思考 / 工具调用 / 等待审批 / 完成（未查看）/ 失败。浅色（Paper Blue）与深色（Sapphire Night）各一组。
