# 外层审批

- `01-approval-collapsed.png`：紧凑行包含允许/拒绝，正文收起；标题和操作分开，按钮可辨。
- `02-approval-allowed.png`：原请求退出待处理或显示已允许，不出现展开正文。
- `03-approval-expanded.png`：完整命令和仅本次范围可读；允许/拒绝仍在外层，没有重复按钮。
- `04-approval-denied.png`：原请求退出待处理或显示已拒绝，没有展开正文或重复操作。

中文 Sapphire Night 及英文 Ink Black 各运行一次。现行主题目录已将 Paper Blue 迁移到 Ink Black，不将其报告为浅色验收。原生 PTY 消费记录应分别只有一条 allow（数字键 1）和 deny（数字键 2）；同时核对观察 Hook 与原题 transcript 回执。
