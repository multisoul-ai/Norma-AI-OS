# workspace-ideas

中文界面。一个项目、一个 Claude 智能体、两条想法（检查登录方案、整理注册流程）。

- `01-ideas.png`：左栏三个标签「对话 / 想法 / 运行概览」，「想法」选中并带中性蓝灰计数 `2`（不是琥珀色）；标题「想法清单」，副标题含「2 条待办」；「待办」分组两行，每行有标题、「刚刚 · 来自对话」、「指派 ▾」与「×」。
- `02-meteor.png`：松手后可能抓到流星尾迹或落点涟漪；允许抓不到（动效约 0.7 秒），此时不判不符合。画面里不应残留拖拽预览条或虚线高亮。
- `03-assigned.png`：智能体卡片边框有短暂高亮或已恢复；想法列表分成「待办 1」与「已指派 1」。
- `04-list-after.png`：「已指派」行有青色圆点与「已交给 Claude」（或「投递中…」）；第二条仍在待办。
- 浅色与深色外观都应可读：抽屉在浅色主题下保持深色玻璃，文字对比度足够。
