# workspace-ideas-compose

一个项目、空的想法清单；依次输入两行带链接的文字、粘贴一张纯色 PNG、再粘贴纯文字。

自动断言（数据与文件）：⇧回车换行、回车添加后库里只有一条正文为“第一行⏎第二行 https://example.com/docs”的想法；粘贴图片后 `idea-images` 下恰好多出 1 个文件，添加后想法的 `images` 记下该文件名且内容与剪贴板一致；剪贴板只有文字时粘贴文字、不新增图片文件。

看图：

- `01-multiline-input.png`：输入框随两行内容增高（最多 5 行），「添加」按钮仍与输入框垂直居中、不被挤出抽屉；占位文字提示“回车添加，⇧回车换行”。
- `02-link-chip.png`：新想法行标题为“第一行”（只取首行），下方有蓝底的链接标签“example.com…”，悬停有更深一档底色。
- `03-pending-image.png`：输入框上方出现 48px 圆角缩略图（橙色纯色），右上角有深色圆形 × 按钮。
- `04-image-row.png`：带图想法行里有 24px 缩略图；添加后输入框上方的缩略图消失。
- 浅色与深色外观都应可读。
