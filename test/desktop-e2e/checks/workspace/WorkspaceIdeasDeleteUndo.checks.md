# workspace-ideas-delete-undo

一个项目、空的想法清单；添加一条想法，悬停行、点删除图标，再点撤销。

自动断言：删除后出现“撤销”提示；点撤销后想法行恢复且提示消失。

看图：

- `01-row-hover.png`：悬停行右侧出现“指派”胶囊和删除图标，× 清晰可见（次要文字色）。
- `02-delete-hover.png`：鼠标在删除图标上时出现圆形浅色状态层，× 仍可见，不是空白灰块。
- `03-snackbar.png`：底部是反色深底（浅色主题下偏深、深色主题下偏浅）的 Snackbar，4px 圆角带投影；文案单行，“撤销”为强调色文字按钮；与输入框有间距、不重叠。
- `04-restored.png`：想法恢复，Snackbar 消失。
- 浅色与深色外观都应可读，“撤销”对比度足够。
