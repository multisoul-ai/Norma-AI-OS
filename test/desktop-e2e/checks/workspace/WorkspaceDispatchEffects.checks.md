# 想法派发特效（真实画布）

参考的 skill 与文档：`review-animations`（动效的目的、时长与可见性）、`docs/design-docs/material-menus.md`。每款特效的时长取自原型：烟花 1.9s、闪电 0.76s、星漩 1.76s。

| 截图 | 要看到 | 不应看到 |
| --- | --- | --- |
| `fireworks-*.png` | 飞行阶段有从想法栏附近升起的金色火箭，随后在卡片上方炸开双色菊花，余烬向下落；末帧特效已消失 | 流星白色光点（说明没有读到烟花设置）、画面里没有任何特效 |
| `lightning-*.png` | 一道带分叉的紫白色闪电连到卡片，随后卡片边缘出现短电弧；第三四张起基本只剩余辉 | 烟花或流星、闪电一直持续到末帧 |
| `vortex-*.png` | 一团蓝紫色星尘旋转着飞向卡片，绕卡片后坍缩成闪光 | 流星、星尘散落在画布以外 |

画面收尾断言：卡片中心及下部飞行走廊恢复到派发前的独立基线；冻结残留不得仅凭最后两帧相同而通过。

数据断言：三条想法最终都是 assigned 且带真实任务引用；动画跨度满足 闪电 < 烟花 − 500ms 且 星漩 > 闪电 + 500ms。
