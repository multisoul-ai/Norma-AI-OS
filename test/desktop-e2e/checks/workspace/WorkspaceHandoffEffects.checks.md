# Agent 交接派发特效（`/ask-norma` 背后的 `agent task assign`）

参考的 skill 与文档：`review-animations`（动效的目的、时长与可见性）。三张假 Agent 并排，源卡片在左（Alan，运行中），目标在右（Bruno）。浅色组使用银白月境壁纸，深色组使用默认太空壁纸。

| 截图 | 要看到 | 不应看到 |
| --- | --- | --- |
| `*-default-*.png` | 白色流星从源卡片右缘出发，横穿中间卡片，在目标卡片上撞击出光环后淡出；末帧无残留 | 离子（短促、480ms 即命中）、动画落在中间或源卡片上 |
| `*-voice-only-*.png` | 橙色火箭从源卡片右缘飞向目标，在目标卡片上方炸开烟花后余烬散落；款式与只设置的语音款式一致 | 流星（说明交接没有跟随语音款式） |
| `*-handoff-override-*.png` | 一道带分叉的蓝白闪电从源卡片连到目标，随后只剩短电弧与余辉 | 烟花或流星（说明显式交接覆盖被忽略） |

数据断言：三种设置 × 浅/深主题共 6 次，经生产 CLI 由源卡片 `agent task assign` 派给目标卡片；每次动画在目标卡片下方区域的峰值变化大于旁观卡片；流星/烟花起点在源卡片右侧；结束后与派发前基线一致；活动跨度（可见区域内，约 180ms 取样）流星 600–1250ms、烟花 1300–2300ms、闪电 0–520ms。

范围说明：时间线保存在 `*-timeline.json`。卡片边框的“运行中”动画与目标卡片顶部的任务回显不属于特效，检测区域已避开。
