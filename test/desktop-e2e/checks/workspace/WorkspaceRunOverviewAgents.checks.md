# workspace-run-overview-agents

中文界面（`NORMA_E2E_LANGUAGE=zh-Hans`），两个项目、两个智能体；假 `claude` 上报 6 项待办（4 完成、第 5 项进行中）并请求一次审批。对照 `docs/design-docs/assets/run-overview-prototype-*-2026-10-19.png`：

- `01-capsule.png`：右上角胶囊是跨项目汇总——满环 + 数量 + 「运行中」、空环 + 数量 + 「待开始」、竖线、琥珀圆形角标 + 「待处理」；不再逐个列出智能体名字和 `4/6`；数字与左栏统计卡一致；无画布顶栏。
- `02-overview.png`：
  - 分段控件选中态为淡蓝填充加描边，「运行概览」带琥珀角标；标题与分组标题左缘对齐。
  - 「需要你处理」带琥珀角标；各分组之间有分隔线。
  - 顶部三张统计卡：待你处理 / 运行中 / 待开始，数字与分组标题计数一致。
  - 分组顺序：需要你处理 → 运行中 → 待开始 → 想法。
  - 智能体行：项目标签、圆点带光晕、「运行中」青色芯片、「1 待审核」琥珀芯片、六段步骤条（4 实心、当前一格半实心）、「第 5/6 项」。
  - 未加载项目行排在「待开始」组尾部：序号小框 `02`、「切换 ↗」，不计入「待开始」的数字。
- 副标题：「工作空间名 · 刚刚更新」；待审核行不再「待审核 · 待审核」，空闲智能体卡片芯片为「待开始」，卡片「等你处理」芯片为琥珀色。
