# WorkspaceHomeDesign 看图清单

每种 dark/light × default/blue 的前缀都核对以下截图；比较同主题两壁纸确实不同。

| 图 | 判断 |
| --- | --- |
| 01-default | 全局壁纸清晰、淡暗角；logo+Norma；头像有X发夹、黑蝴蝶结和绿色点；问候/640搜索/最近居中；四张252×204等宽卡、预览不透明、无旧大标题和打开按钮 |
| 02-hover | 仅目标卡上浮约2px，阴影加深，⋮可见；其他卡无变化 |
| 02-pressed | 按下状态层清晰；卡片回到点击锚点，松开后直接打开，不能与hover位移叠加 |
| 03-focus | Tab焦点清晰3px主色环，菜单触发器可见；不靠hover识别焦点 |
| 04-menu | 菜单锚定卡片右下，未被其他卡覆盖，重命名/删除完整可读，删除红色 |
| 05-delete-confirm | 删除进入现有确认流程，取消可用 |
| 06-search | 原位向下展开；35%遮罩，品牌约45%、最近约20%；分组数量/更早折叠/上下选择提示清晰 |
| 07-older-expanded | 显示全部后可滚动到所有旧空间，无越窗或圆角泄露 |
| 08-match | 只显示匹配搜索结果并高亮中文匹配；选中行有主色背景与回车提示 |
| 09-empty | 无结果文案、预填新建入口，最近背景不会被误当结果 |
| 10-prefilled-create | 创建弹窗已填HomeNewDraft，取消可用 |
| 11-one | 空间与虚线新建卡整体居中，尺寸不膨胀，顶部仍保留次要新建按钮 |
| lifecycle-01-renamed | 单卡显示新名称，菜单未遮住标题，目录持久化断言通过 |
| lifecycle-02-welcome | 删除最后空间后恢复现有欢迎页，重启保持为空 |

焦点回归仅在 `dark-default` / `light-default` 组合补验：

| 图 | 判断 |
| --- | --- |
| 12-command-input | `/help`完整显示在底部命令输入框，首页仍为胶囊，无搜索结果/无结果面板 |
| 13-close-escape | Tab到关闭按钮再Esc，等待后续帧后仅显示搜索胶囊，无遮罩或分组反弹 |
| 13-older-escape | Tab到显示全部再Esc，同样稳定关闭 |
| 14-reopened | 点击关闭后重新输入“插件”，仍能展开并显示插件市场/匹配高亮 |

额外：减少动态效果用 `MULTISOUL_REDUCE_MOTION=1` 复跑相关状态；高频键盘反馈即时。窄窗检查最后一张卡的菜单完整落在窗口内，不被后绘制卡片遮挡。0空间由既有欢迎页测试/生命周期场景验证。

只有看过实际截图才能填写符合；全黑截图、OCR无文字和截图文件存在均不构成视觉通过证据。
