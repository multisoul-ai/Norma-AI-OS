# 工作空间进度抽屉：保留原型

唯一视觉参考：`fullscreen-push-drawer.png`。窗口和全屏共用同一推开式抽屉；右上角“项目进度”打开，关闭按钮或抽屉内 Esc 关闭。

- 默认当前工作空间，切换查看范围不切画布；点击任务才定位项目与卡片，抽屉保持展开。
- 项目分组显示已经加载的智能体；只读项目元数据，未运行项目不自动启动。
- 状态与最近进展分开：Hook／进程给出运行、审批、失败和本轮结束；标题、阶段和说明是 Agent 最近一次汇报，并带更新时间。
- 不展示估算百分比；新轮次清除旧阶段，结束后保留最后进展并标记本轮结束。
- 抽屉宽度最多360px，窄窗占42%；剩余宽度统一用于画布、终端、浏览器与输入栏。
- 使用现有主题语义色与组件焦点反馈，保持主卡片布局。开关即时完成，避免反复调整终端尺寸。

图中旧的“当前动作”在实现中使用“最近进展”；图像是布局参考，不是实时事实或验证证据。
