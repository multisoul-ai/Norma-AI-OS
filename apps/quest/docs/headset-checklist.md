# Quest 3 真机验收

状态：待连接真实 Quest 3 执行；不得用构建成功替代。

1. 开启开发者模式，用 USB 连接 Mac，在头显中允许 USB 调试；`adb devices` 显示 `device`。
2. Mac 终端运行 `scripts/quest.sh mock`，另一个终端运行 `scripts/quest.sh run`。
3. 应用出现在未知来源应用列表；启动后显示真实房间和三张空间面板。
4. 主窗口点击「连接 Mac」：状态从未连接 → 正在连接 → 已连接，出现 MOCK 标识及 CLI 样例。
5. 用控制器选择第二项决策：只对应 Codex 任务恢复，Claude 待办仍然存在。重连后待办不恢复。
6. 用控制器移动窗口；检查窗口保持世界位置、内容朝向正确，UI 点击不会误触抓取。
7. 手部射线、捏合与近距离直接触碰分别检查；未通过的输入方式不得在发布说明中标为支持。
8. 停止 mock 服务：连接状态显示断开，决策按钮禁用。重启后手动重连。
9. 切到系统菜单/关闭应用后连接应释放，返回应用可重新连接。
10. 持续使用 20 分钟，记录设备系统版本、CPU/GPU 帧时间、掉帧、温度与文字舒适度。

证据保存在本地 `outputs/`，记录实际结果，勿提交设备标识或日志中的私人内容。
