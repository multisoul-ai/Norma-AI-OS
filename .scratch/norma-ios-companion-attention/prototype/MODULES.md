# Norma iOS 伴侣 · 当前原型

假数据可点原型，对应已锁定的工作空间模型。不做「需要你 / 摘要 / 锁屏」。

## 三页

```text
空间列表
   └─► 空间页     时间线、发言、顶部成员
          └─► 进度页   本空间任务、优先级、谁在做
```

## 已锁定、原型要体现的行为

- 一件事一个空间；时间线只追加；默认成员是你和 Norma
- 频道即工作空间，可绑多个项目；Agent 在空间内共享
- 一条任务只落一个项目；没写仓库时 Norma 选主项目并说明
- 没点名 Agent 的指令交给 Norma 拆任务、标优先级；讨论只回复
- 显式 `@` 且说清动作：直接建任务，请求人是你，Norma 不改派
- 只 `@`、没说动作：只加入成员，Norma 追问
- 多个 `@`：一人一条任务
- `@Norma`：交给幕僚长
- 进度是单独一页
